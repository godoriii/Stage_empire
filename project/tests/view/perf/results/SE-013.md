# SE-013 성능 재측정 결과: 군중 그림자 off (구성 E) + 비교 구성 A~D

상태: **측정 대기(사람 실행 필요)**. SE-004 셰이더 시안 캡처·비용 측정과 같은 날 한 번에 요청한다(docs/status/2026-W41.md C3+C4).
원본 JSON: `docs/reports/perf/SE-013-{B,E}.json`(필수), `SE-013-{A,C,D}.json`(선택), dGPU 기기는 `SE-013-{B,E}-dgpu.json`.
qa 가 유효성 절차(docs/reports/SE-003.md "측정 후 절차" 그대로, 관문 구성만 E·기기별 기준 60/30)를 거친 뒤 아래 표로 옮긴다.

## 구성 (spike_configs.tres)

| 구성 | 인스턴스 | 라이트 | 셰도우 라이트 | 아틀라스 | 군중 그림자 (`crowd_shadows`) | 비고 |
|---|---|---|---|---|---|---|
| A | 5,000 | 32 | 0 | 2048 | on | 하한 |
| B | 5,000 | 32 | 8 | 2048 | on | 비교용(군중 그림자 on) |
| C | 5,000 | 32 | 32 | 2048 | on | 상한 |
| D | 10,000 | 32 | 8 | 2048 | on | 여유 확인 |
| E | 5,000 | 32 | 8 | 2048 | **off** | **관문 구성** (B 와 같고 군중 그림자만 off) |

군중 영역(한 변 약 50.5 m), 프록시 메시(708 tri), 라이트 연출 상수는 SE-003 과 같다(B 와 E 비교 가능).

**무대 프록시(셰도우 캐스터)**: 모든 구성(A~E)에 `StageProps` 아래 BoxMesh 6개(3 × 2 × 2 m, 각 12 tri, **합계 72 tri**, `cast_shadow` ON).
셰도우 라이트가 놓인 앞줄(화면 안쪽) 아래 한 줄로 놓여 군중 그림자를 꺼도 셰도우 패스가 비지 않는다.
A~D 의 primitives 는 SE-003 대비 메인 패스 +72, 셰도우 패스(B·C·D)에서는 프록시가 라이트 면 안에 들어가는 만큼 더 늘어난다
(llvmpipe 참고: 프록시 몫 프레임당 약 +730 tri = B 의 0.0008%, 군중 3.54M 대비 무시 가능). 오버레이 라벨 문구가 바뀌어 글리프 삼각형도 수십 개 다르다.

**관문 판정 (E 기준): 측정 대기.** 기준: **E 평균 fps ≥ 60(dGPU/Vulkan) 또는 ≥ 30(M1/Iris Xe 급)** (ADR-0001 재측정 조건).
측정기 콘솔은 `gate_min_avg_fps` 60 으로만 "통과/실패"를 찍는다. M1·Iris Xe 급 기기는 qa 가 JSON `gpu` 로 기기를 구분해 30 기준으로 다시 판정한다.
판정 줄은 "통과/실패" 한 줄, 수식어 없이 적는다.

보조 확인(AC11):

| 구성 | primitives / (인스턴스 × 708) | 기대 | `gpu_timing_available` | `bound_hint` |
|---|---|---|---|---|
| B | | 25.0 (SE-003 과 같음) | | |
| E | | 1.0 + 무대 프록시 셰도우 몫(≈ 0.0003) — 군중 셰도우 패스 0 | | |

Vulkan 기기면 `gpu_timing_available == true` 이고 `bound_hint != "unknown"` 이어야 한다. Metal(M1)은 `false`, `gpu_timing_note` 에 이유가 남는다(정상).

### 에이전트 환경 참고 수치 (무효, 판정에 쓰지 않음)

render-engineer 가 Xvfb + Mesa llvmpipe(`--rendering-method gl_compatibility`, `rendering_driver=opengl3`)에서 단축 실행(예열 2 s, 측정 8 s)으로 얻은 값.
`run_valid=false`(렌더러·단축 위반). 프레임 시간은 CPU 래스터라 의미 없고 primitives 구조만 본다.

| 구성 | 평균 ms | draw calls | primitives | primitives / (5000 × 708) |
|---|---|---|---|---|
| A | 1,100.07 | 21 | 3,540,320 | 1.00009 |
| B | 4,542.46 | 119 | 88,500,968 | 25.00027 |
| E | 1,925.34 | 96 | 3,540,982 | 1.00028 |

- E 는 군중 셰도우 패스가 0 이다(비 1.0003). E − A = 662 tri 가 무대 프록시의 셰도우 패스 몫이고, draw calls 21 → 96 으로 셰도우 패스가 실제로 돈다.
- E 의 프레임 시간은 A 보다 길다(llvmpipe 1.75 배). 셰도우 맵 렌더 자체는 작아도 메인 패스에서 셰도우 라이트 8개의 그림자 샘플링 비용이 남기 때문으로 보인다(추정, llvmpipe 는 프래그먼트 비용이 과장된다). 실제 GPU 에서의 크기는 실측으로 확인한다.

## 측정 방법

저장소 루트에서, Godot 에디터를 닫고, 전원 연결(노트북), 다른 무거운 프로그램 없이. 각 구성 약 40초 뒤 스스로 종료.

```bash
# macOS(M1): 새 씬·class_name 캐시를 먼저 임포트한다(.godot/ 은 gitignore 라 체크아웃 직후 비어 있다)
godot --headless --path project --import
mkdir -p docs/reports/perf
COMMIT=$(git rev-parse --short=12 HEAD)
for c in B E; do
  godot --path project res://tests/view/perf/measure_spike.tscn -- --config=$c \
    --out="$PWD/docs/reports/perf/SE-013-$c.json" --commit=$COMMIT
done
# 선택(시간 있으면): for c in A C D; do ... 같은 명령 ... done  → A~E 5행을 채운다
```

Windows PowerShell:

```powershell
godot --headless --path project --import
New-Item -ItemType Directory -Force docs/reports/perf | Out-Null
$COMMIT = git rev-parse --short=12 HEAD
foreach ($c in "B","E") {
  godot --path project res://tests/view/perf/measure_spike.tscn -- --config=$c `
    --out="$PWD/docs/reports/perf/SE-013-$c.json" --commit=$COMMIT
}
```

- dGPU(Vulkan) PC 가 있으면 같은 명령을 한 번 더 돌려 `docs/reports/perf/SE-013-{B,E}-dgpu.json` 으로 저장(파일명 접미사만 다르게).
- 콘솔 마지막 줄 `관문(E 평균 ≥ 60 fps): 통과/실패/무효` 와 JSON 을 그대로 넘긴다.
- 조건 위반(`run_valid=false`)이면 숫자와 관계없이 무효. `run_issues` 가 헤드리스, VSync 켜짐, forward_plus 아님, 해상도 불일치,
  예열 시간 < 10 s, 예열 프레임 < 120, 측정 시간 < 30 s 를 잡는다. 단축 인자(`--warmup-sec=` 등)를 쓰면 자동으로 무효가 된다.
- `--out` 이 없으면 `user://perf/SE-013_<config>.json`.
- 구성 E 실행 중 화면 한 장 캡처(군중에 그림자가 없고 무대 박스에는 그림자가 있는지 육안 확인). SE-004 캡처와 같이 보낸다.
- 구경(측정 아님): `godot --path project res://view/perf/spike_crowd.tscn -- --config=E`.

## JSON 키 → 표 열

| 표 열 | JSON 키 |
|---|---|
| 군중 그림자 | `crowd_cast_shadow` (씬의 실제 `cast_shadow != OFF`), 구성 값은 `crowd_shadows` |
| 평균 fps | `avg_fps` |
| 1% low fps | `p1_low_fps` (가장 느린 ceil(1%) 프레임의 평균 프레임 시간으로 낸 fps) |
| 평균 ms | `avg_frame_ms` |
| 최대 ms | `max_frame_ms` |
| draw calls | `draw_calls` (측정 구간 프레임 평균, `RENDER_TOTAL_DRAW_CALLS_IN_FRAME`) |
| primitives | `primitives` (측정 구간 프레임 평균, `RENDER_TOTAL_PRIMITIVES_IN_FRAME`) |
| GPU 타이밍 가용 | `gpu_timing_available` (= `avg_gpu_ms > 0`), 불가 이유 `gpu_timing_note`(드라이버 이름 포함) |
| 병목 힌트 | `bound_hint` (`gpu`/`cpu`/`unknown`) |
| 무대 프록시 | `stage_prop_count_actual`, `stage_prop_tris` |
| 유효성 | `run_valid`, `run_issues`, `gate.verdict` |
