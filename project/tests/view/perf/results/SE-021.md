# SE-021 외곽선 시안 비용: 구성 E 에 plain / b / ss

상태: **Xvfb 무효 측정만(참고값)**. 유효 fps 는 사람 실측 대기(다음 관문, 다른 측정과 묶음).
측정 진입점은 SE-013 그대로(`measure_spike.tscn`), JSON 의 `ticket` 은 `SE-013`, 시안은 `material` 키로 구분한다.

## 시안

| material | 머티리얼 | 외곽선 |
|---|---|---|
| plain | 정점색 `StandardMaterial3D`(`material_override = null`) | 없음 |
| b | `toon_b.tres` + next_pass `outline_b.tres` | 역면 헐 2 px(군중·무대를 한 번 더 그림) |
| ss | `toon_ss.tres`(= toon_b 파라미터, next_pass 없음) + 스파이크 직속 포스트 패스 노드 1개 | 깊이 텍스처 스크린스페이스 2 px(전체 화면 쿼드 1장) |

## 무효 측정(Xvfb, llvmpipe, gl_compatibility, 1920×1080, 예열 1초·5프레임, 측정 3초, 구성 E, 커밋 전 작업 트리)

```bash
xvfb-run -a -s "-screen 0 1920x1080x24" godot --path project --rendering-driver opengl3 --resolution 1920x1080 \
  res://tests/view/perf/measure_spike.tscn -- --config=E --material=<plain|b|ss> \
  --warmup-sec=1 --warmup-frames=5 --measure-sec=3 --out=<scratch>/<material>.json
```

| material | 인스턴스 | 군중 그림자 | primitives | ÷ plain | draw calls | − plain | 유효 fps |
|---|---|---|---|---|---|---|---|
| plain | 5,000 | off | 3,540,972 | 1.000 | 95 | — | 사람 실측 대기 |
| b | 5,000 | off | 7,081,396 | 2.000 | 132 | +37 | 사람 실측 대기 |
| ss | 5,000 | off | 3,540,968 | 1.000 | 96 | +1 | 사람 실측 대기 |

- `run_valid == false`(Xvfb·예열/측정 단축) — fps 는 소프트웨어 렌더러 값이라 표에 옮기지 않는다(0.58~0.78 fps).
- ss 의 primitives 는 plain 과 같다(차 −4 는 프레임 평균 반올림 잡음, 쿼드 2 tri 는 그 안에 묻힌다). 외곽선이 군중을 다시 그리지 않는다.
- ss 의 비용은 primitives 가 아니라 **픽셀 셰이더**(1080p 전 화면, 픽셀당 깊이 샘플 13개 + 주름 후보 이웃마다 13개)에 있다.
  이 비용은 GPU 실측에서만 보인다 → 사람 관문 측정 필수.
