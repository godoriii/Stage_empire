# SE-004 셰이더 시안 비용: 구성 E 에 default / A / B / C

상태: **측정 대기(사람 실행 필요)**. SE-013 AC11 재측정과 같은 날·같은 커밋에서 한 번에 요청한다(티켓 "테스트 방법 — 사람 PC", C3+C4).
원본 JSON: `docs/reports/perf/SE-004-E-{default,a,b,c}.json`, dGPU 기기는 `SE-004-E-<material>-dgpu.json`.
JSON 의 `ticket` 은 `SE-013` 그대로다(측정 진입점이 같다). 시안은 파일명과 `material` 키로 구분한다.
qa 가 유효성(`run_valid == true`, `config == "E"`, `material` == 파일명, `instance_count_actual == 5000`, `crowd_cast_shadow == false`)을 확인한 뒤 아래 표로 옮긴다.
통과 기준은 없다(아트 디렉터의 시안 선택 자료). 콘솔의 관문 판정 줄은 default 행에서만 의미가 있다.

## 시안 (project/view/shaders/params/)

| material | 머티리얼 | 셀 단계 | 외곽선 | 림라이트 |
|---|---|---|---|---|
| default | 기존 `StandardMaterial3D`(정점색 albedo), `material_override = null` | — | 없음 | 없음 |
| a | `toon_a.tres` + next_pass `outline_a.tres` | 2 | 1 px | 없음 |
| b | `toon_b.tres` + next_pass `outline_b.tres` | 3 | 2 px | 있음 |
| c | `toon_c.tres` + next_pass `outline_c.tres` | 2 | 2 px | 있음 |

적용 대상: 군중 `$Crowd`(MultiMesh 5,000, 708 tri) + 무대 프록시 `$StageProps/*`(BoxMesh 6개, 72 tri). 바닥·라이트는 그대로.
구성 E 의 값(인스턴스·라이트 32·셰도우 라이트 8·아틀라스 2048·군중 그림자 off)은 `spike_configs.tres` 그대로다.

## 측정 명령 (티켓 "테스트 방법" 블록과 동일)

```bash
# 저장소 루트. macOS(M1): 새 씬·class_name 캐시를 먼저 임포트한다
godot --headless --path project --import
mkdir -p docs/reports/perf
COMMIT=$(git rev-parse --short=12 HEAD)
for m in default a b c; do
  godot --path project res://tests/view/perf/measure_spike.tscn -- --config=E --material=$m \
    --out="$PWD/docs/reports/perf/SE-004-E-$m.json" --commit=$COMMIT
done
```
