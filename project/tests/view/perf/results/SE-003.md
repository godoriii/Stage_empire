# SE-003 성능 스파이크 결과: 인스턴싱 캐릭터 5,000 + 동적 라이트 32

상태: **측정 대기(사람 실행 필요)**. 에이전트 환경에는 GPU 가 없다(Mesa llvmpipe, Vulkan 없음 → forward_plus 로 못 돈다).
아래 표는 GPU 가 있는 PC 에서 측정 스크립트를 돌린 JSON 으로 채운다. 표를 채우기 전에는 관문 판정을 하지 않는다.

## 측정 PC

| 항목 | 값 (JSON 키) |
|---|---|
| GPU | (`gpu`, `gpu_vendor`) |
| CPU | (`cpu`, `cpu_cores`) |
| RAM | (`ram_gb`) |
| OS | (`os`) |
| 드라이버 | (`gpu_api`, `gpu_driver`) |
| Godot 버전 | (`godot_version`) |
| 커밋 해시 | (`commit`, `-dirty` 가 붙으면 작업 트리 변경이 있던 측정) |
| 해상도 | 1920×1080 (`resolution` 이 `requested_resolution` 과 같아야 함) |
| VSync | off (`vsync` == `"off"`) |
| 렌더러 | forward_plus (`renderer`, `rendering_driver`) |

관문 판정: 측정 대기 (구성 B `avg_fps` ≥ 60 이면 "통과", 아니면 "실패" + 아래 분석 단락)

CPU/GPU 바운드 분석(실패 시): 구성 B JSON 의 `avg_gpu_ms`(GPU 렌더 시간), `avg_render_cpu_ms`(렌더 CPU), `avg_crowd_update_ms`
(GDScript 군중 보간·버퍼 업로드 + 라이트 갱신), `avg_process_ms`(Performance.TIME_PROCESS), `bound_hint` 로 쓴다.

최소 사양(Intel Iris Xe 30fps): 검증 불가(해당 하드웨어 없음). 하드웨어가 생기면 같은 명령으로 측정하고 이 줄을 바꾼다.

## 측정 방법

저장소 루트에서, Godot 에디터를 닫고, 전원 연결(노트북), 다른 무거운 프로그램 없이:

```bash
mkdir -p docs/reports/perf
for c in A B C D; do
  godot --path project res://view/perf/spike_crowd.tscn -- --measure --config=$c --out="$PWD/docs/reports/perf/SE-003-$c.json"
done
```

Windows PowerShell:

```powershell
New-Item -ItemType Directory -Force docs/reports/perf | Out-Null
foreach ($c in "A","B","C","D") {
  godot --path project res://view/perf/spike_crowd.tscn -- --measure --config=$c --out="$PWD/docs/reports/perf/SE-003-$c.json"
}
```

- `--out` 이 없으면 `user://perf/SE-003_<config>.json` (Linux `~/.local/share/godot/app_userdata/Stage Empire/perf/`,
  Windows `%APPDATA%\Godot\app_userdata\Stage Empire\perf\`).
- 각 실행은 약 40초(예열 10초 + 측정 30초) 뒤 스스로 종료하고, 콘솔에 위 표 형식의 한 행과 관문 판정을 찍는다.
- 측정 스크립트가 런타임에 VSync off, 프레임 제한 해제, 테두리 없는 1920×1080 창을 설정한다(`project.godot` 은 바꾸지 않는다).
- JSON 의 `run_valid` 가 false 면(`run_issues`: 헤드리스, VSync 켜짐, forward_plus 아님, 해상도 불일치) 그 측정은 표에 넣지 않고 다시 잰다.
  관문 구성에서 조건 위반이면 `gate.verdict` 가 "무효"다.

## JSON 키 → 표 열

| 표 열 | JSON 키 |
|---|---|
| 평균 fps | `avg_fps` |
| 1% low fps | `p1_low_fps` (가장 느린 ceil(1%) 프레임의 평균 프레임 시간으로 낸 fps) |
| 평균 ms | `avg_frame_ms` |
| 최대 ms | `max_frame_ms` |
| draw calls | `draw_calls` (측정 구간 프레임 평균, `RENDER_TOTAL_DRAW_CALLS_IN_FRAME`) |
| primitives | `primitives` (측정 구간 프레임 평균, `RENDER_TOTAL_PRIMITIVES_IN_FRAME`) |
