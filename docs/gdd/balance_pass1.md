## 1. 원인 진단 (AC1)

표기: 기준 배치 `baseline_show`(수용 122, 음향 ∩ 시야 94칸, 편의 가산 100, 유지비 123), 명성 0, 노이즈 0 이 기본. "전" = SE-042 측정 때 데이터.

### D1. 무작위 정책이 파산하지 않는다 (M7 random 0 %, 합산 0 %)

**공식.** 하루 순이익 `net(p) = p·N(p) + 12·⌊0.6·N(p)⌋·0.65 − 600 − upkeep − G`(세전 양수면 ×0.9). 입장 `N(p) = Σ_t e_t(p)`, `e_t(p) ∝ clamp(10000 − s_t·(p − 20), 0, max_bp)`(audience AD4). 유형별 티켓 매출 최대 가격은 `p*_t = (10000 ÷ s_t + 20) ÷ 2`.

| 원인 | 전 수치 | 결과 |
|---|---|---|
| 가격 반응이 무디다 | `s` = 단골 200 / 팬 300 / 뜨내기 500 → `p*` = 35 / 26.7 / 20. 싼 가격 상한 `price_factor_max_bp` 20,000(가격 5 에서 뜨내기 ×1.75) | 로컬 s07 의 `net(p)`: 가격 5 → +52, 10 → +477, 20 → +828, 30 → +639, 40 → −101. **가격 5~40 중 적자는 40 근처뿐** |
| 무작위 섭외의 개런티 부담이 없다 | 12명 중 신인 4명은 명성 150 전에는 `grade_locked`로 거절(개런티 0, 그날 −431 = 임대 + 유지비 − 단골 매출). 로컬 8명은 개런티 400 으로 항상 감당 | 개런티 800 을 내는 날이 거의 없다(30판 135 공연 포기, `insufficient_cash` 3건) |
| 여유 | 시작 5,000 − 개점 2,140 = 2,860 + 구제 2회(각 `deficit + 3,000`) | 평균 일 순이익이 음수가 아니면 30일 안에 파산할 수 없다 |

**무작위 하루의 기대 순이익**(로컬 8명 × 가격 5..40 균등, 명성 0): 전 **+170**(적자인 조합 33 %). 실측 30일 평균 +359/일(명성이 오르며 입장 증가, 최저 최종 자금 5,386). 무작위가 파산하려면 평균이 대략 −150 이하여야 한다(2,860 → 0 이 약 19일, 구제 뒤 상환 330/일이 더해져 25~30일에 두 번째 구제를 다 씀).

### D2. 실패 공연이 0 건이다 (M4 random disaster+poor 0 %, M11 판정 불가)

**공식.** 에이전트 만족 `= ⌊(4000·lineup + 1500·sound + 1500·sight + 3000·value − 500·crowd) ÷ 10000⌋ + bonus`(audience SF6~SF8).

| 원인 | 수치 |
|---|---|
| 만족의 바닥이 높다 | 기준 배치는 94명까지 음향·시야 둘 다 10,000 → 3,000 이 무조건 들어온다 + 가산 100. 라인업 최저 = 적합 6,000 × 실력 계수 5,900 = 3,540 → ×0.4 = 1,416. 가격 40(value 0)에서도 에이전트 최저 ≈ **4,516** |
| 등급 임계가 0~10,000 눈금에 맞춰져 있다 | 부진 3,000 / 보통 5,000. 공연이 열린 날의 실제 분포는 4,500~8,700(모델, 무작위 1,400 공연) → 5,000 아래는 1 % 미만, 3,000 아래는 0 |
| 비싼 가격의 벌이 약하다 | value 는 `5000 − s_t·(p − 20)`: 가격 40 에서 단골 1,000 이 남는다. s07 가격 40 평균 5,420(보통) |

### D3. 시드 분산이 거의 없다 (frugal `rep500_day` [22, 22], aggressive [15, 15], 등급 한 칸)

| 원인 | 공식·수치 |
|---|---|
| 입장 노이즈가 좁다 | `noise_bp` 1,000 → 입장 ±10 %(s07 74~91) |
| 명성 계수가 일찍 포화 | RG3 `f = clamp(N ÷ 100, 0.5, 1.0)`. 입장 100 이상이면 노이즈와 무관하게 `f = 1` — 절약형은 5일 전후, 공격형은 2일부터 포화 → 그 뒤 Δ 는 매일 같다 |
| 만족은 노이즈 밖에서 결정적 | 만족 = f(아티스트, 가격, 입장). 입장 ≤ 94 면 입장과도 무관. 절약형 만족 분포 6,000~7,250 은 호평 구간 [6,000, 7,500) 안에, 공격형 7,250~8,500 은 대부분 열광(≥ 7,500)에 있다 → 등급이 시드와 무관하게 한 칸 |

### D4. 첫 선택 유발 사건이 늦다 (M8 frugal 7일, aggressive 5일)

| 사건 | 공식 | 전 |
|---|---|---|
| 신인 해금 | `Σ Δ ≥ unlock_reputation(rookie)` = 150, Δ ≈ 18, 18, 18, 21… | 설계 8일, 봇 7일 |
| 승급 | s07 인기 27 + 2/호평 ≥ 40 | 7번째 공연 |
| 만석 | `E ≥ 122` — 명성 ≈ 230(절약형 10일), 공격형은 개점 투자로 5일 | 5~10일 |
| 실패·구제 | D1·D2 로 일어나지 않음 | — |

## 3. 봇 확인 실행 (game-designer, 참고)

`tools/bot/play_bot.sh --policy <id> --seeds 30 --days 30`(정책 3 + `v0_replay` 시드 36), 결과 파일은 리포지토리 밖. 판정은 qa 재측정(docs/reports/SE-065.md)이 한다.

무작위 정책만 끝까지 돌았다(시드 1..30, 30일, 이 브랜치 데이터). 절약형·공격형·`v0_replay` 확인 실행은 작업 중단(턴 한도)으로 기록하지 못했다 — qa 재측정에서 판정한다. 절약형은 첫 4판(시드 1·9·17·24)만 나왔고 전부 파산 없음, 최종 자금 40,032~44,900, 명성 697~725.

| 파산율 | 0 % (0/30) | **46.7 % (14/30)** | 30~90 % | 안 |

**새로 드러난 문제(M11).** 실패 공연(부진)은 이제 흔하지만, 실패일 하루 순이익(−514)이 포기일(−477)보다 낮다. 무작위의 부진은 대부분 비싼 가격(입장 급감 + 개런티 400)에서 나오기 때문이다(가격 35: 입장 16, 순이익 −492). "포기가 지배 전략이 아니다"(M11)를 지키려면 2차 후보: (a) 개런티를 공연 결과와 엮는 규칙(새 규칙 — 결정 로그 필요), (b) `price_factor_min_bp`를 0 에서 올려 비싼 가격에도 단골·팬 일부가 남게(예: 3,000), (c) 포기일 비용을 올리기(임대는 economy checks 때문에 어렵다). 추천 (b) — 데이터 1필드, 실패 공연에 바 매출이 남는다.
