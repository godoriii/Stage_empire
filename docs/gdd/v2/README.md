v2 는 건설이 없는 **로그라이트 프로모터** 게임이다. 공연마다 준비 5기둥을 정하고, 자동으로 흐르는 공연을 보며 돌발 카드에 답하고, 원인별로 쪼갠 성적표를 받고, 보상 카드 1장을 고른다.
설계 원칙: **결정 → 눈에 보이는 결과 → 한 줄 이유.** 만족도의 모든 감점 줄은 준비 결정 하나(또는 돌발 카드의 선택 하나)로 되돌아간다.

## 데이터 테이블 (`docs/gdd/v2/data/`)

`project/data/` 의 v0 스키마 검증과 섞지 않는다(결정 로그 2026-10-20). Godot 이식 때 `project/data/` 로 옮기며 스키마를 붙인다. 지금은 `python3 -m json.tool` 문법 검사만.
각 행의 `status` 가 `final` 이면 1막 확정치, `draft` 면 2막 이후 대략치(봇 검증 전).

| 파일 | 내용 |
|---|---|
| `balance.json` | 시작 자금·명성, 만족도 기준값, 등급 임계·명성 변화, 집객 계수, 만족도 줄 계수(가중치·상한), 미리보기 경고선, 수정자 클램프, RNG 스트림 id |
| `acts.json` | 막 4개: 공연 수, 제안 수, 시장 크기, 돌발 수, 외상 한도, 라인업 슬롯, 열리는 손잡이, 티켓 가격 단계, 홍보 단계, 5구간 프로필, 제안 템플릿, 관문 |
| `venues.json` | 장소(수용·대관료·음향·기본 화장실 칸·바 자리·집객 보정·특성) |
| `artists.json` | 장르 4(소란도) + 아티스트(집객·실력·개런티·적정 티켓값) |
| `staff.json` | 인력 역할(보안·바텐더·청소·의료): 막별 일당·처리량·최소/최대 |
| `facilities.json` | 시설(화장실 추가 칸·푸드 부스·음향 등급·의료 텐트·바 부스): 막별 대여비·처리량·최대 |
| `events.json` | 돌발 카드 |
| `rewards.json` | 보상 카드 풀, 등급, 막별 등급 확률, 종류 가중치 |

## 용어

| 용어 | 뜻 |
|---|---|
| 런 (run) | 1막 시작부터 실패 또는 피날레 클리어까지 한 판. 자금·명성·보유 카드는 런 안에서만 유지 |
| 막 (act) | 1막 클럽 → 2막 공연장 → 3막 야외 페스티벌 → 피날레(4) |
| 공연 (show) | 제안 → 준비 → 개최 → 결과 → 보상의 한 바퀴. 런 전체 13회 |
| 관문 (gate) | 막의 마지막 결산 공연. 등급·명성 조건을 못 넘으면 런 실패 |
| 제안 카드 (offer) | 다음 공연의 조건: 요일/성격 템플릿(집객·대관료·명성 배율·협찬) + 트렌드 장르(랜덤) |
| 트렌드 (trend) | 제안 카드에 붙는 '요즘 뜨는 장르'(OFFER 스트림 int(4)). 테마가 트렌드와 같으면 수요 +10 % (`balance.demand.trend_demand_pct`) |
| 테마 (theme) | 플레이어가 준비 기둥 0 에서 고르는 공연 장르(4장르 중 1, 필수). 헤드라이너 장르 = 테마면 수요 +20 %·만족 +2, 오프닝 장르 ≠ 테마면 1팀당 만족 −2 (show.md) |
| 아티스트 시장 (market) | 이번 공연에 섭외 가능한 아티스트 목록(막 풀에서 무작위 N명) |
| 준비 5기둥 | 장소 · 라인업 · 시설 · 인력 · 티켓/홍보 (+ 기둥 0: 제안·테마) |
| 헤드라이너 / 오프닝 | 헤드라이너 구간 / 오프닝 구간에 서는 아티스트 |
| 집객 (draw) | 아티스트가 데려오는 관객 수(기준값) |
| 실력 (skill) | 무대 품질 0~100. 만족도 줄로 들어간다 |
| 적정가 (fair_price) | 팬들이 이 아티스트에 낼 만하다고 보는 티켓값. 넘기면 감점 |
| 수요 / 입장 (demand / att) | 오고 싶은 사람 수 / 실제 들어온 사람 수(= min(수요, 수용)) |
| 구간 (segment) | 개장·오프닝·전환·헤드라이너·마감 5개. 공연은 구간 단위로 계산 |
| 처리량 | 바텐더 1명·화장실 1칸이 한 구간에 처리하는 인원, 보안 1명이 감당하는 인원 |
| 못 간 사람 (miss) | 그 구간에 바·화장실을 원했지만 처리되지 못한 인원(보안은 감당 못 한 인원) |
| 만족도 줄 (line) | 만족도 = 기준값 + 줄들의 합. 줄마다 원인 하나 |
| 분위기 | 개최 중 실시간 게이지 = 그 구간까지 실현된 줄의 합(마감 값 = 최종 만족도) |
| 등급 | S/A/B/C/D. 만족도 임계로 정한다 |
| 수정자 (modifier) | 보상 카드가 공식에 거는 보정. 키 + 퍼센트(pct) 또는 정수(add) |
| 대비 카드 (shield) | 특정 태그 돌발 카드를 피해 없이 넘기는 1회용 선택지를 주는 카드 |
| 외상 한도 (credit) | 준비 비용이 자금을 넘어도 이 금액까지는 계약 가능(정산은 공연 후) |
| 금액 단위 | 만원. 모든 금액은 정수 |
