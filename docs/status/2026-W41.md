# 주간 상태 2026-W41 — 에이전트 셋업

결론: 에이전트 9종, 경계 hooks, 리포지토리 골격이 들어갔다. 프리프로덕션 1차 티켓 6개(SE-001~SE-006)를 파일로 만들었고 전부 "대기"다. 다음은 1차 배정(SE-006 + SE-002).

## 제한

처음 2주(W41~W42)는 동시 에이전트 **3개 이하**: producer + reviewer + qa 를 상수로 두고, 엔지니어는 한 번에 하나만.
규칙이 작동하는지(hook 차단, 티켓 흐름, 리뷰 반려→새 티켓) 확인한 뒤 나머지를 푼다.

## 사람이 결정할 것

- Godot **4.6** 로컬 설치(GUT 9.6.1 과 짝). `godot` 을 PATH 에 두거나 `GODOT_BIN` 설정.
- GitHub Projects 보드 생성과 브랜치 보호 규칙(main: PR 필수, CI 필수). 리포지토리 설정은 에이전트가 못 한다.
- Git LFS 활성화(`.gitattributes`는 준비됨, `git lfs install` 은 로컬에서).
- **SE-003 측정 실행.** 에이전트 환경에는 GPU 가 없다. 스파이크 씬이 나오면 사람 PC 에서 `godot --path project res://view/perf/spike_crowd.tscn -- --measure --config=B`(A~D) 를 1회 돌려 결과 JSON 을 qa 에 넘겨야 한다. 이게 없으면 ADR-0001 조건부 결정을 확인할 수 없다.
- **`project/project.godot` 수정 권한.** `run/main_scene`, `[input]` 액션은 어느 에이전트 쓰기 범위에도 없다. 선택지: (a) 사람이 직접 편집(추천, 변경 빈도 낮음) (b) `tools/hooks/boundary_policy.json`에 render-engineer 허용 경로로 `project/project.godot` 추가. SE-002 는 (a) 전제로 런타임 `InputMap` 등록과 씬 경로 인자 실행으로 진행한다.
- **스크린샷 자동 비교 CI.** `tools/run_tests.sh`는 `--headless`라 화면 캡처가 안 된다. 선택지: (a) 당분간 스크린샷은 qa 수동 검수(추천, 프리프로덕션 동안) (b) CI 에 xvfb + opengl3 러너를 추가해 골든 이미지 비교 자동화(별도 티켓). SE-002/SE-004 는 (a) 전제.
- SE-004 완료 후 **셰이더 시안 A/B/C 선택**(아트 디렉션). SE-005/SE-006 완료 후 각 "열린 질문"(구제 횟수·방식, 세금 v0 포함 여부, 저녁 2배속 허용, 공연 중 일시정지 불가 유지)을 이 파일에 올린다.
