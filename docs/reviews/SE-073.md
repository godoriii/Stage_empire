## 발견 사항
**M1 (중간, AC6 미충족)** `app.js:48-50` recordRun 의 중복 방지 키 `seed + ":" + history.length` 가 서로 다른 런을 같은 런으로 본다.
- 웹은 `lastAct: 1`(`:7`)이다. 그래서 결산까지 간 런은 모두 `history.length = normal_shows+1` 로 끝난다.
- "같은 시드로 다시"(`:770`)로 다시 한 판은 결과(통과/실패)가 달라도 기록되지 않는다. 처음에 실패하고 다시 해서 통과하면 `passes` 가 빠진다.
- 고칠 방법: `startRun` 에서 `app.recorded = false` 로 두고, recordRun 은 이 플래그만 본다. hot 복원용으로 snapshot 에도 `recorded` 를 넣는다.

**M2 (중간, 접근성/조작)** `style.css:236-238` 의 `glow` 애니메이션이 `box-shadow` 를 덮어쓴다.
- 그 결과 유니크·레전더리 카드를 골라도 선택 표시(`.rcard.on`, `:205`)가 보이지 않는다. 남는 것은 `aria-pressed` 뿐이다.
- 고칠 방법: 빛은 `outline`·`filter: drop-shadow` 나 `::after` 같은 다른 속성으로 낸다. 아니면 `.rcard.on.unique/.legendary` 에서 glow 를 끈다.

**L1 (낮음, hot 복원)** `snapshot`(`:813-815`)과 `restore`(`:824-843`)에 새 필드가 빠져 있다.
- `preShow` 가 없다. 공연 중에 복원하면 `app.state` 가 바로 공연 전 상태인데도 `app.preShow` 를 정하지 않는다. 그래서 그 공연의 '이랬다면'이 조용히 사라진다.
- 고칠 방법: 복원 화면이 `show` 이면 `app.preShow = app.state` 를 넣는다. 결과 화면 복원까지 살리려면 snapshot 에 preShow 를 넣는다.
- `revealed` 도 없다. 보상 화면에서 복원하면 `app.revealed` 가 undefined 로 남아, 카드를 누를 때마다 뒤집기 연출이 다시 나온다(`:714`). 복원할 때 `revealed = true` 로 두면 된다.

**L2 (낮음)** 움직임 줄이기 설정에서 float 요소가 쌓인다.
- 이 설정에서는 `.float` 에 `animation: none` 이 걸려(`style.css:240`) `animationend` 가 오지 않는다. 그래서 `app.js:434` 의 제거가 일어나지 않고, 화면이 바뀔 때까지 숨은 span 이 쌓인다.
- 고칠 방법: `reduceMotion` 이면 float 를 만들지 않는다.

**L3 (낮음)** `loadLocal`(`:32-35`)이 값의 모양을 검사하지 않는다.
- 저장된 값이 `"null"` 이면 `records`·`tipsSeen` 가 null 이 되고, 타이틀 렌더(`:750`)나 `tip()`(`:44`)에서 TypeError 가 난다. 필드가 빠진 값이면 NaN 이 된다.
- 고칠 방법: 객체인지 확인하고 `{...fallback, ...v}` 로 합친 뒤, 기록 값은 `Number()` 로 바꿔서 출력한다.
- try/catch 는 읽기와 쓰기 모두에 있다(`:33,35`). 저장 실패는 무시되고 메모리 값으로 계속 동작한다(통과).

**L4 (낮음)** `tip-ok`(`:806`)이 화면 전체를 다시 렌더한다.
- 결과 화면에서는 도장과 숫자 올라가기가 다시 재생된다.
- 버튼이 없어지면서 포커스가 body 로 간다. 고칠 방법: 다시 렌더한 뒤 섹션 제목에 포커스를 준다.

**L5 (낮음)** 테스트·QA 근거가 부족하다.
- `docs/reports/SE-073.md` 가 없다.
- `smoke.mjs` 는 콘솔 오류와 가로 넘침만 본다. whatIf·cardDelta·기록·안내·움직임 줄이기는 검사하지 않는다. 티켓의 "약 13 % 감소" 같은 수치는 원시 출력이 없어 확인할 수 없다.

## 확인한 것 (통과)
- **rAF 루프** (`:476-483`): `app.raf` 가드가 있어 루프가 하나만 돈다. `screen !== "show"` 이거나 `!app.sim` 이면 멈추고 `raf = null` 로 돌아간다. `finishLive` 가 `anim` 과 `floatedBeats` 를 초기화한다. 공연 중에 빠져나가는 경로는 없다.
- **움직임 줄이기**: 프레임 1장만 그린다. k=1, 진폭 0, 조명은 끈다. 도장·뒤집기·숫자 올라가기를 생략하고, CSS 에서도 막는다(AC1). `matchMedia?.()` 는 체인 단락 평가라 해당 API 가 없어도 안전하다.
- **기록 중복 집계**: 런이 기록되는 경로는 `nextShow` 의 no_show 와 `to-over` 두 개뿐이다. 둘은 서로 배타적이다. hot 복원으로 다시 집계되는 경우도 없다. 반대로 덜 집계되는 문제는 M1 이다.
- **esc**:
    - 카드 이름과 효과는 `esc` 로 처리한다.
    - float 은 `textContent` 로 넣는다.
    - whatIf 라벨은 데이터 숫자와 고정 문자열뿐이다.
    - 기록 숫자는 localStorage 에서 읽은 값인데 그대로 출력한다. L3 에서 `Number()` 로 바꾸는 것으로 해결한다.
- **접근성**: float 은 `aria-hidden` 이고 같은 내용이 피드에 있다. 안내는 `role="note"`, 도장은 `aria-label` 을 단다.

## 참고 (규칙 근거 없음)
- whatIf 의 기준 만족도(분산 0·돌발 없음)는 위에 보이는 실제 만족도와 다르다. 각주가 있지만 "같은 조건 기준 X" 라고 적으면 덜 헷갈린다.
- 취소선 값(`:182`)에는 `won()` 을 쓰지 않아 단위가 없다. 화면 읽기 프로그램에는 `<s>` 가 "원래 값"으로 전달되지 않는다.
- `cchip` 의 전체 효과는 `title` 에만 있어 터치나 키보드로는 볼 수 없다.
- whatIf 의 `pre.show_idx` 검사에 `pre.seed === app.state.seed` 를 더해 두면 방어가 더 단단해진다.
- `startLive` 에서도 `anim`·`floatedBeats` 를 초기화해 두면 안전하다.

## 반려 시 새 티켓 제안
**SE-0xx 1막 손맛 후속: 기록·보상 선택 표시·복원 다듬기**
