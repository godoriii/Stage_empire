## 발견 사항 (심각도 높음→낮음)

- **[중간] `tools/bot/mutate_and_test.sh:67-72` vs `:80-81`: 심링크 뒤의 `..` 와 아직 없는 꼬리가 겹치면 리포지토리 안 판정을 우회한다.** 원인은 두 연산의 경로 해석 방식이 다른 것이다. `[ ! -d "$p" ]`(:67)와 `mkdir -p`(:80)는 커널이 물리 경로로 푼다. `cd "$p"`(:72)는 bash 기본값이 논리 모드라 `..` 를 글자 단위로 먼저 지운다.
  - 예: `/tmp/L → <repo>/project` 이고 `SE_MUTATE_DIR=/tmp/L/../x` 이며 `<repo>/x` 가 없을 때.
    - :67 은 `/tmp/L/..`(물리 경로 = `<repo>`)에서 멈춘다. :72 의 `cd "/tmp/L/.."` 는 `/tmp` 로 가므로 `BASE_PRE=/tmp/x` 가 되어 통과한다.
    - :80 의 `mkdir -p` 는 물리 경로로 `<repo>/x` 를 만든다.
    - :81 의 `cd` 는 논리 경로 `/tmp/x` 가 없으면 원문 경로로 다시 시도해 `BASE=<repo>/x` 가 된다. 그 결과 사본이 리포지토리 안에 생긴다.
  - 상대 경로도 같다. 심링크로 들어간 `$PWD` 에서 `SE_MUTATE_DIR=../x` 를 주면(:66 이 논리 `$PWD` 를 붙인다) 같은 결과다.
  - 피해: 정상 종료면 :92 가 사본을 지워 빈 디렉터리만 남는다. `--keep` 이나 kill 이면 SE-016 `_mut_tmp` 와 같은 untracked 잔여가 남는다. 기존 파일 삭제는 없다.
  - 이 경우 README:22 와 스크립트 :8 의 "리포지토리 안이면 디렉터리·사본을 만들기 전에 exit 2" 가 거짓이 된다. 티켓 범위가 지시한 실경로 `$BASE` 사후 검사(`:62 뒤 case "$BASE" in "$ROOT"|"$ROOT"/*) … exit 2`)는 사전 검사로 대체되면서 빠졌다. 결과 절에도 그 사실이 없다.
  - 승인을 막지 않는 이유: AC2 문구의 케이스는 통과한다. 전제(리포지토리를 가리키는 심링크 + `..` + 없는 꼬리)가 드물다. main 의 현 코드(리포지토리 안 `SE_MUTATE_DIR` 를 그대로 받아들임)보다 엄격히 낫다.
  - 고치기: :72·:81 을 `cd -P` 로 바꾼다. `$BASE` 전체에 `..` 성분이 있으면 거부한다(꼬리만이 아니라). :81 뒤에 실경로 `$BASE` 사후 검사(`"$ROOT"|"$ROOT"/*` → exit 2)를 방어선으로 하나 더 둔다.
- **[낮음] `:72`, `:81`: `cd` 실패가 판정을 빈 문자열로 만든다.**
  - :72 의 `echo "$(cd "$p" && pwd -P)$rest"` 는 `cd` 가 실패해도 0 을 돌려준다. 그러면 `BASE_PRE` 가 `$rest` 만 남아(예: `""`, `/x`) 리포지토리 검사를 지나간다.
  - :81 의 `BASE="$(cd "$BASE" && pwd -P)"` 에는 `|| exit 5` 가 없다. 실패하면 `BASE=""` 가 되고, `mktemp -p ""` 사본은 :92 패턴(`/se_mutate.?*`)에 맞지 않아 경고와 함께 남는다.
  - 어느 경우에도 삭제 범위는 넓어지지 않는다. 다만 가드 전체가 `$BASE` 실경로에 기대므로 실패를 삼키면 안 된다.
  - 고치기: 함수 안에서 `local r; r="$(cd -P "$p" && pwd -P)" || return 1` 로 바꾸고, :81 에 `|| exit 5` 를 붙인다.
- **[낮음] `:92`: `$BASE` 가 `/` 이면 삭제 패턴이 `//se_mutate.?*` 가 된다.** 실경로 `/se_mutate.X` 와 맞지 않으므로 넓어지지 않고 좁아진다(fail-safe). 하지만 `SE_MUTATE_DIR=/` 에서는 매 실행 사본이 경고와 함께 `/` 에 남는다. 이 환경은 root 라 실제로 만들 수 있다. 고치기: 패턴을 `"${BASE%/}"/se_mutate.?*` 로 바꾸거나 `$BASE` 가 `/` 이면 exit 2.
