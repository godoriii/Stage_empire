## 목표

프로덕트 오너 결정(2026-10-23): 다음 단계는 "1막 손맛 다듬기". 규칙·수치는 그대로 두고, 같은 1막이 더 읽히고 더 기분 좋게 느껴지게 화면과 연출을 다듬는다.

## 수용 기준

- [x] AC1. 개최: 관객 수가 부드럽게 늘고, 점이 구간 열기·분위기만큼 들썩이며, 헤드라이너 구간에 조명이 돈다. 새로 실현된 만족도 줄이 무대 위에 떠오른다. 움직임 줄이기 설정이면 정지 화면.
- [x] AC2. 결과: 등급 도장·숫자 올라가기 연출, '이랬다면' — 가장 큰 감점(보안·화장실·바·티켓값) 결정 하나만 바꿔 공연 전 상태로 엔진 `evaluate` 를 다시 돌린 만족도·등급·수지 변화(규칙을 화면에서 계산하지 않음).
- [x] AC3. 보상: 카드가 뒤집히며 공개, 유니크·레전더리 빛. 준비 화면에 적용 중인 카드 목록, 장소 대관료 원래 값 취소선, 미리보기에 '카드 효과'(카드 없이 엔진을 한 번 더 불러 비교한 비용·예상 관객·경고 차이).
- [x] AC4. 준비 화면: 장소·아티스트 카드를 한 줄 사실 목록으로 줄여 휴대폰 세로 길이 감소(375px 전체 페이지 스크린샷 높이 3379 → 2950, 약 13 %, 리포트 원시값).
- [x] AC5. 첫 판 안내 4곳(제안·준비·개최·결과), '알겠어요'로 닫고 이 브라우저에 기억(localStorage, 실패해도 동작).
- [x] AC6. 타이틀에 런 기록(런 수·1막 통과·최고 만족도·최고 명성), 이 브라우저에만 저장.
