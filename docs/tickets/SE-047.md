## 목표

SE-026 리뷰가 남긴 두 묶음을 닫는다. (A) 심링크 뒤 `..` 와 아직 없는 꼬리 경로로 "리포지토리 안" 판정을 우회하는 경로를 막는다. (B) 변이 사본의 기준선이 `run_tests.sh` 결과와 같아지게 한다(지금은 사본에 `docs/` 가 없어 문서를 읽는 테스트 3건이 Pending, 요약 awk 가 Pending 을 실패로 셈).

## 범위

- 포함(A): `mutate_and_test.sh` 의 경로 판정·이동을 `cd -P` 로, 경로 전체에서 `..` 성분 거부(exit 2), `mkdir`·`cd` 뒤 실경로 `$BASE` 사후 검사(리포지토리 안이면 만든 디렉터리 정리 후 exit 2), `cd` 실패 시 exit 2, `$BASE` 가 `/` 이면 exit 2(또는 `"${BASE%/}"` 패턴). README·스크립트 머리 주석의 "만들기 전에 exit 2" 문구를 실제 동작과 맞춤.
- 포함(B): 사본에 `docs/` 를 읽기 전용으로 함께 복사(또는 테스트가 읽는 경로만)해 빈 패치 기준선 Pending 0; 요약 스크립트의 "실패한 테스트" 목록에서 Pending 제외.
- 제외: 예시 패치 변경, shellcheck CI.
