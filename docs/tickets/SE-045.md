## 목표

SE-044 가 남긴 낮음 2건을 닫는다: Build(RS1 거절)와 Economy(문자열이면 통과)의 스냅샷 phase 검사 비대칭, 그리고 `core/sim_config.gd`·`core/tick.gd` 에 남은 private `_as_int`(2^63 가드 없음)를 `JsonUtil.as_int` 로 통합.

## 범위

- 포함(game-designer): economy.md 스냅샷 절 phase 조건을 "sim.json phases id 중 하나(아니면 복원 거절, push_error 1회)"로 한 줄 수정 + 변경 이력.
- 포함(sim-engineer): `Economy._parse_snapshot`(또는 restore) 의 phase 검사를 `SimConfig.PHASE_IDS` 로(모르는 값 → false + push_error 1회, 상태 불변); `core/sim_config.gd`·`core/tick.gd` 의 `_as_int` 를 `JsonUtil.as_int` 호출로 교체(동작 불변, 오류 문구 유지); 테스트 2건(`phase:"noon"` 스냅샷 거절, `seed: 1e19` 거절).
- 제외: 다른 시스템 변경, 스키마 변경.
