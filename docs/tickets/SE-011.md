## 목표

경제(이후 관객·아티스트 등) 시스템의 상태가 `TickLoop.snapshot()` 에 들어가고 `restore()` 로 되살아나는 규칙을 tick.md 에 고정한다.
지금 `TickLoop.register_system(id, update: Callable)` 는 `update` 만 받고, `snapshot()` 은 시간·RNG·명령 큐 9개 키만 돌려준다(`project/core/tick.gd`).
economy.md 는 "`Economy.snapshot()/restore()` 는 있지만 `TickLoop` 스냅샷과의 연결은 구현 티켓에서(Q7)" 로 미뤄 두었고,
리뷰 3건(docs/reviews/SE-001.md 참고 4, docs/reviews/SE-005.md "tick.md v0 정합성" 스냅샷 API 부재, docs/reviews/SE-006.md)이 같은 공백을 지적했다.
이 문서만 보고 sim-engineer 가 SE-012 에서 `tick.gd` 확장과 `test_tick.gd` 케이스를 질문 없이 쓸 수 있으면 끝이다. **코드·데이터 변경은 하지 않는다**(아래 "데이터 적용 시점" 참조).
