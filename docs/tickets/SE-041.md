## 목표

(1차) 규약(슬롯 = 서피스)을 실제 에셋으로 처음 검증한다: 무대(대형, `base`+`accent`+`emissive`), 바 카운터(`base`+`accent`), 스피커(`base`+`emissive`), 음료 냉장고(`base`+`glass`+`emissive`), 스포트 스탠드(`base`+`emissive`) — 5개, 린터 통과, 검수 큐 INDEX 갱신. 사람 검수(아트 디렉션)는 **MVP 플레이 테스트(SE-043) 때 한 번에** — 미승인이면 게임은 프록시 메시로 돈다. (2차, R-B) 슬롯 서피스를 가진 메시에 시안을 적용할 때 서피스별 슬롯 머티리얼(`base`/`accent`/`emissive` 툰 + 외곽선, `glass` 는 알파 블렌드·외곽선 없음·그림자 없음), 오브젝트 단위 인스턴스 파라미터(복제 금지), 군중 인스턴스 색은 `base` 만.

## 범위

- 포함(1차): AI 3D 생성 또는 수작업 모델링 → Blender 정리(슬롯 이름·피벗·예산) → `.glb` 5개 + `META.json` 5개 + `python3 -I tools/assets/lint_gltf.py` 결과 `lint.json`(전부 pass) → `project/assets/review-queue/<furniture_id>/` + `INDEX.md` 행 5개(에셋 id·티켓·날짜·검사 결과·상태 "검수 대기") + 미리보기 PNG 1장씩(Xvfb `probe_import.gd` 류 렌더 — 선택). 결과 절에 생성 도구·프롬프트·실패한 시도 수(파이프라인 통계 — PRD "사람 개입 1회" 검증).
