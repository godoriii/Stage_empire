## 목표

close 구간에 저장한 게임을 불러오면 마감 리포트의 정산 행(R6 매출, R7 비용, R8 순이익)이 0 으로 보인다. 정산 값이 `economy.day_settled` 이벤트로만 나가고 sim 상태에 남지 않기 때문이다. Economy 가 마지막 정산 결과를 스냅샷에 보관하고, `GameSession.hud_state()` 가 그것을 돌려주게 한다.

## 범위

- 포함(game-designer): economy.md #스냅샷에 `last_settlement`(마지막 `day_settled` 페이로드와 같은 키, 새 게임은 빈 값) 1줄, 스냅샷 키 수 갱신.
- 포함(sim-engineer): `Economy` 가 `day_settled` 발행 때 같은 값을 `last_settlement` 로 보관·스냅샷·복원(전부 검사 후 일괄 적용 규칙), `GameSession.hud_state()` 에 포함. 테스트.
- 포함(render-engineer): `day_report.gd` 가 `session.loaded` 뒤 `hud_state().last_settlement` 로 R6~R8 을 채움. 테스트.
- 제외: 정산 공식 변경.
