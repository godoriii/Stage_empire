## 목표

SN1 정규식 `^[a-z0-9_]{1,24}$` 의 `$` 가 끝 개행 하나를 허용해 `"a\n"` 슬롯이 저장되고 `a\n.sav` 파일이 생긴다. 경로 이탈은 아니고 지금은 슬롯 이름을 사용자가 입력하지 않지만, 입력 UI 가 생기기 전에 막는다.

## 수용 기준

- [ ] AC1. events.md SN1 정규식이 끝 개행을 거부(`\z` 또는 동등 표현) + 변경 이력. (game-designer)
- [ ] AC2. 코드 `SLOT_PATTERN`·`is_valid_slot` 이 문서와 같다. `"a\n"` 무효, `"a"` 유효. (sim-engineer)
- [ ] AC3. `"a\n"` 저장 → push_error 1, 이벤트 0, 파일 0. 불러오기 → `load_failed{invalid}`. (sim-engineer 테스트)
- [ ] AC4. qa 헬퍼 `_doc_sn1_pattern`(`test_session_contract_qa.gd`)이 새 표기를 읽는다. 계약 대조 테스트 녹색. (qa)
- 참고(같은 브랜치에서 선택): `GameSession.COVERAGE_CAUSE_RELOAD` → `COVERAGE_CAUSE_SYNC` 이름 정리(SE-058 리뷰 참고).
