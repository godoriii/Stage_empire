## 목표

SE-051 리뷰 낮음 3건을 닫는다. CI 의 preview.png 바이트 비교가 러너 zlib 에 묶이지 않게 하고, 슬롯 키 불일치를 원인이 보이는 메시지로 알리고, 주석을 사실대로 고친다.

## 범위

- 포함(art-pipeline): `tools/assets/` 에 PNG 디코드 비교 도구(또는 생성기 `--compare <dir>` 옵션) — `.glb`·`META.json`·`lint.json` 은 바이트, `preview.png` 는 픽셀 비교. 슬롯 키 ≠ 서피스 이면 `KeyError` 대신 "slots 키 ≠ 서피스: …" 오류, `furniture_json` 인자를 쓰는 테스트 1건(안 쓰면 인자 삭제). 주석 :35·:37 에 "R-B 전에는 자리표시 색이 화면에 그대로 보인다".
- 포함(메인 세션): ci.yml 비교 단계를 새 도구로 교체.
- 포함(SE-043 인계): 에셋 이동 커밋에서 CI 비교 대상 경로도 함께 갱신 — SE-043 AC4 에 한 줄.
- 제외: 형태·색 변경.
