## 목표

틱마다 오는 `audience.agent_moved {tick, agents: [[id, px, pz, state, type], …]}`(좌표 1/100 m 정수, 5칸 — audience.md Q5) 를 받아 MultiMesh 150 인스턴스(스파이크의 프록시 캡슐 재사용, 시안 B, 그림자 off)를 **이전 틱 → 현재 틱 위치로 프레임 보간**해 그린다. 유형별 인스턴스 색(`audience.json` 유형 색), 상태별 간단 표현(`watching` 은 무대 방향, `at_bar` 는 정지, `leaving` 은 반투명 금지 — 색만). 공연 구간(`show.started` ~ `show.ended`)에 무대 스포트 2~4개 켜기(가구 `light_grade` 합계로 개수, `show.ended.grade` 로 끝 연출 1종).

## 범위

- 포함: `project/view/crowd/crowd_view.gd`(`CrowdView`: MultiMesh, 활성 인스턴스 수 = 에이전트 수, id → 인스턴스 슬롯 매핑, 보간 `t = acc/tick_len` 은 `_process` 에서 **표시만** 갱신), `project/view/stage/stage_lights.gd`(`StageLights`: SpotLight3D ≤ 4, `show.*` 구독), 테스트 `test_crowd_view.gd`(가짜 버스 2틱 주입 → 인스턴스 수·중간 프레임 위치 = 선형 보간값·색), `test_stage_lights.gd`, 캡처 1장 `screenshots/SE-038/crowd150_show_yaw45_zoom2.png`(샌드박스 `--se-crowd-preset=150` + 스포트 on). 스파이크 측정기(`measure_spike`)에 "대표 장면" 구성 F(가구 20 + 군중 150 + 스포트 4) 행 추가 — 실측은 사람 GPU 관문 묶음(materials.md Q4 "서피스 수별 draw calls" 행도 여기).
- 제외(다른 티켓): 임포스터·흐름장(티어 4+), 캐릭터 에셋(프록시 캡슐 유지 — 실제 캐릭터 glTF 는 VS), 오디오, 파티클·안개(VS), HUD(SE-039).
