## 목표

프로덕트 오너가 고른 **시안 B**(셀 3단계 + 외곽선 2px + 림라이트, `project/view/shaders/params/toon_b.tres` + `outline_b.tres`)가
`--material=` 인자 없이도 **모든 view 씬의 기본 머티리얼**이 된다. 지금은 세 진입점(샌드박스 `grid_sandbox.gd`, 스파이크 `spike_crowd.gd`, 측정기 `measure_spike.gd`)이
`ShaderVariants.DEFAULT_ID == "default"`(= `material_override = null`, 정점색 StandardMaterial3D)를 기본으로 쓴다. 이 티켓 뒤에는 기본값이 `"b"` 이고,
예전 룩은 비교용 id `"plain"` 으로만 남는다. `--material=` 은 비교용으로 유지한다(a/b/c/plain). 시안 .tres 의 수치는 바꾸지 않는다(룩 수치 변경 0).
동시에 reviewer 발견(낮음) — `ShaderVariants.load_material()` 이 유효 id 의 `.tres` 로드 실패를 조용히 `null` 로 돌려주는 것 — 을 `push_error` 로 고친다.
스크린샷 기준(SE-002 1장·SE-004 4장)은 "같은 명령으로 Xvfb 재캡처 → 기존 파일 교체·파일명 유지" 규칙으로 갱신한다.

## 범위

- 포함(render-engineer):
  - `project/view/shaders/shader_variants.gd`: `DEFAULT_ID = "b"`, `IDS = ["plain", "a", "b", "c"]`, `SELECTABLE_IDS = ["a", "b", "c"]` 불변. `"plain"` 은 `load_material()` → `null`(의도된 값, `push_error` 없음), `apply()` → `material_override = null`. `"default"` 는 더 이상 유효 id 가 아니다(없는 id 와 같은 오류 메시지).
  - `load_material(id, path_pattern := MATERIAL_PATH_PATTERN) -> ShaderMaterial`: 유효하고 `plain` 이 아닌 id 의 리소스 로드가 `null` 이면 `push_error("ShaderVariants: 시안 '<id>' 머티리얼 로드 실패: <경로>")` 후 `null`. `apply(root, id, exclude := [], path_pattern := MATERIAL_PATH_PATTERN)` 는 그 경우 **아무 노드도 바꾸지 않고 -1**(없는 id 와 같은 처리). `path_pattern` 인자는 테스트가 로드 실패를 만들기 위한 것(기본값이면 동작 동일).
