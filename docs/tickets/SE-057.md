## 목표

SE-036 이 남긴 데이터·문서 요청을 닫는다. 오토세이브 보관 수와 수동 슬롯 수를 데이터로 옮기고, 로드 재발행 예외를 문서에 적고, 30일 기준값을 승인하며, 해금 회귀가 CI 에서 돌게 한다.

## 범위

- 포함(game-designer)
  - `project/data/save/save.json` + `schemas/save.schema.json`: `manual_slots`(기본 3), `autosave_keep`(기본 3, 0 = 무제한).
  - events.md `reputation.changed` 행에 "로드·새 게임 재발행 1회(`delta:0`)" 예외. `by_genre` 키 순서가 계약인지 명시.
  - `build.coverage_changed.cause` 에 `"load"` 를 추가할지 결정(추천: 추가하지 않고 `sync` 재사용 — 구독자가 같은 처리를 함).

- 포함(sim-engineer): `GameSession` 이 `save.json` 을 읽어 보관 수 적용(없으면 무제한 유지). 리플레이 테스트의 티어 조건(30000·500 등 리터럴)을 `ReputationConfig.tier_threshold()` 등에서 읽기. 해금 단언을 기본 6일 리플레이에서도 도는 형태로 옮길 수 없으면 qa 에 30일 CI 잡 명령을 넘긴다.
- 포함(메인 세션): CI 에 `SE036_LONG=1` 30일 리플레이 잡 1개(별도 job, 약 2분).
- 제외: 세이브 슬롯 UI 변경(SE-040 이 `manual_slots` 를 읽는다).

**결정 3가지**

1. `reputation.changed`: 불러오기·새 게임 재발행 1회(`delta: 0`, 경계에서, 상태 불변)를 "하루 1회" 의 예외로 명문화. **`by_genre` 키 순서는 계약이 아니다**(키 집합 = `mvp_genres` 만 계약, 소비자는 키로 읽는다). → 순서 보장 접근자·순서 테스트는 필요 없음(SE-036 리뷰 후속의 "순서가 계약이면" 조건 불성립).
2. `build.coverage_changed.cause`: `"load"` 추가하지 않음. 재발행은 `"sync"` 재사용(현재 `GameSession.COVERAGE_CAUSE_RELOAD = "sync"` 그대로, enum 불변).
3. 30일 통합 기준값 승인: 명성 500 21일, 자금 30,000·티어 2 해금 22일, 30일 끝 자금 41,294·명성 756(봇 v0: 시드 36, 아티스트 1명·가격 20 고정). 설계 기준 25일은 그대로 두고 차이 원인만 기록(조정은 SE-042). 개런티 8일차 400 → 800 은 `thumbnail_soda`(인기 27) 의 7번째 호평 공연 뒤 `local → rookie` **승급**(artist.md GR4·GR5, `guarantee_by_grade.rookie` 800) — 버그 아님. 테스트는 리터럴 일치가 아니라 범위 단언 IB1~IB4.

**sim-engineer 에게 넘길 것 (같은 브랜치 다음 단계)**

- 읽기 경로: `<data_root>/save/save.json` (기본 `res://data/save/save.json`). `GameSession.load_configs(data_root)`/`new_game` 에서 읽는다(SV1).
- 필드: `autosave_keep: int`(0 = 무제한) → `GameSession.autosave_keep`. 파일·키 없음 → 0(무제한, SV4). `int` 아님·음수 → `push_error` 1회 후 0(SV5). 적용 규칙 SV3 은 현재 `_prune_autosaves()` 와 같다(수동 슬롯은 세지 않음, 쓰기 실패 경계에서는 지우지 않음 — 이 두 점을 테스트로 고정).

- 주의: 실제 데이터에 `autosave_keep: 3` 이 생기므로, 기본 데이터 루트로 4일 이상 돌며 "기본 무제한" 을 단언하는 테스트(`test_autosave_unlimited_by_default_and_disable` 등)는 `save/` 가 없는 데이터 루트(또는 주입)로 바꿔야 한다. AC2 는 tick.md SV 절 끝의 수용 기준 문장 그대로.
