## 목표

`godot --path project` 한 줄로 실행되는 메인 씬: 시작 메뉴(새 게임 시드 입력·불러오기) → `GameSession.new_game(seed)` → 그리드·카메라·가구·군중·HUD·패널이 한 버스에 붙어 티어 1 루프가 실시간으로 돈다. `SimDriver` Node 가 `_process(delta)` 에서 `session.step(delta)` 만 부른다(배속은 sim 이 결정, 일시정지는 `speed 0`). 창 닫기 전 오토세이브 확인 없음(마감 오토세이브로 충분). 이 티켓이 끝나면 "플레이해볼 것" 에 메인 씬 명령이 올라간다.

## 범위

- 포함: `project/view/runtime/sim_driver.gd`(`SimDriver`: `session` 주입, `_process` → `step(delta)`; 프레임 델타 상한은 `sim.json.max_ticks_per_step` 이 sim 쪽에서 처리하므로 view 는 자르지 않음), `project/view/scenes/main.tscn/.gd`(조립: `GameSession` 생성은 **view 가 아니라** `project/core/game_session.gd` 의 팩토리 호출 — view 는 참조만 들고 `bus` 를 하위 뷰에 배포), `project.godot` `main_scene` 설정은 사람(C2 와 같은 경로 — 결과 절에 1줄; 없어도 `godot --path project res://view/scenes/main.tscn` 로 실행), `--se-seed=<n>`·`--se-load=<slot>`·`--se-screenshot=` 인자, 통합 테스트 `project/tests/e2e/test_main_scene.gd`(헤드리스: 씬 로드 → 새 게임 → `advance` 로 1일 진행 → HUD 라벨·가구 노드·군중 인스턴스 수가 sim 스냅샷과 일치; 저장 → 로드 → 뷰 재구성), 캡처 2장 `screenshots/SE-040/main_day1_evening.png`(시드 0, 기준 배치 프리셋, 저녁 입장 중), `main_show.png`(공연 중 150명 + 스포트). `recapture.sh` 는 qa 가 갱신(10·11번째).
- 제외(다른 티켓): 내보내기 프리셋(`export_presets.cfg` — 사람·메인 세션, MVP 는 에디터 실행으로 플레이), 오디오, 튜토리얼, 설정 화면.
