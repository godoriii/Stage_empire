## 목표

CI `screenshots` job 을 보고 모드에서 **실패 조건이 있는 모드**로 바꿀 수 있게 한다. 러너(Ubuntu llvmpipe)는 로컬 기준 PNG 와 5장 모두 ≈21.5k px(1%) 차이가 나지만 러너 안에서는 결정적이다(1차·2차 동일). 차이 **영역**(bbox)을 알아야 러너 기준 PNG / 마스크 / 허용 오차 중 무엇을 고를지 정할 수 있다. 함께 reviewer 발견 1~3(상대 경로 out_dir 해석, 거부 전 `mkdir`, 아티팩트 재실행 409, 티켓 YAML 블록 불일치)을 닫는다.

## 범위

- 포함(qa 1차):
  - A. `project/tests/view/screenshots/recapture.sh`: `cd` 전에 `CALLER_PWD="$PWD"` 를 잡아 `$1` 을 호출자 cwd 기준으로 절대화; 리포지토리 안 경로 거부 검사를 통과한 **뒤에** `mkdir -p`; `:16` `cd … || exit 2`. CI 호출(`$RUNNER_TEMP/shots` 절대 경로)·qa 로컬 절차의 동작·출력 불변.
  - C-1. `project/tests/view/png_compare.gd` `PngCompare.diff` 반환 Dictionary 에 `diff_bbox: [x0, y0, x1, y1]`(다른 픽셀이 없으면 `[]`) 추가, `compare_png.gd` 출력 줄에 `diff_bbox=<x0,y0,x1,y1>` 덧붙임. 선택 인자 `--max-diff-pixels=<n>`(`n` 초과면 exit 1; `--strict` 는 `n = 0` 과 같다). 단위 테스트: bbox 1건(합성 이미지 두 영역 → 포함 상자), `--max-diff-pixels` 경계 1건. 비교 루프는 기존 바이트 루프에 얹는다(비용 증가 없음).
  - C-2. 진단: CI 2차 아티팩트(screenshots-37929144407)의 러너 캡처 5장 vs 커밋 기준 5장을 새 비교기로 돌려 bbox 와 원인 후보(HUD 폰트 / Mesa 버전·AA / 외곽선 서브픽셀)를 `docs/reports/SE-025.md` 에 기록. 아티팩트를 받을 수 없으면 PR 의 `screenshots` job(`if: always()` 업로드)에서 받는다.
  - C-3. **strict 전환 방식 제안**(리포트 "producer 에게" 절): (1) 러너 전용 기준 PNG 세트 `project/tests/view/screenshots/ci/` + `--strict`, (2) bbox 가 HUD 등 고정 영역이면 마스크 뒤 `--strict`, (3) `--max-diff-pixels=<n>` 허용 오차. 각각 장단 1줄 + 추천. producer 가 결정 로그에 채택하고 2차(메인 세션)가 ci.yml 에 반영한다.
  - 셰이더 오류 경로 불변 확인: 스크래치 사본 `toon.gdshader` 에 문법 오류 주입 → `recapture.sh` exit 1 + 패턴 메시지(SE-020 AC2 와 같은 절차, 결과 3줄 리포트).
- 포함(메인 세션 2차): ci.yml `upload-artifact` 에 `overwrite: true`(또는 이름에 `run_attempt`) 1줄; 채택안에 따라 비교 step 의 `STRICT_FLAG`/마스크/기준 경로 1~2줄. `docs/tickets/SE-020.md` YAML 블록을 HEAD ci.yml 과 글자 단위로 동기화(producer 가 티켓 파일에서).
- 제외(다른 티켓): 기준 PNG 자체 교체(룩 변경이 아니므로 하지 않는다. 채택안 (1)이면 **러너 캡처를 `ci/` 에 추가**하는 것이지 기존 기준을 바꾸는 것이 아니다). CLAUDE.md "명령어" 절에 `recapture.sh` 1줄 — producer 가 "사람이 할 일" 선택 항목으로.

- 테스트: `test_png_compare.gd` 7 → 11(+4: bbox, 크기 불일치 bbox, 경계 판정, CLI exit 코드 통합). `tools/run_tests.sh` sim 72 / view 101 전부 통과, `validate_data.py` 실패 0.

**진단(C-2)** — CI 2차 아티팩트 5장 vs 기준: 5장 모두 `diff_bbox=28,16,593,198`(HUD 패널), 상자 밖 차이 0(3D 장면은 바이트 동일). 원인은 러너에 한글 시스템 폰트가 없어 HUD 한글이 두부(□)로 그려지는 것. 추천 **(2) HUD 영역 마스크 + `--strict`**(`--ignore-rect` 옵션은 qa 후속 필요), 근거·3안 비교는 리포트.

**메인 세션이 적용할 ci.yml 변경안**
- 이 PR 에서는 **변경 없음**: 비교 step 이 비교기 출력을 `tee` 로 그대로 남기므로 `diff_bbox=` 는 코드 변경만으로 CI 로그·`*.diff.txt` 에 찍힌다. (`upload-artifact` 의 `overwrite: true` 와 이름의 `run_attempt` 는 main 에 이미 반영돼 있음 — 확인 필요 시 `git diff` 로.)
- strict 전환은 producer 결정 뒤. 채택안별 1~2줄:
  - (3) 허용 오차: `STRICT_FLAG: "--max-diff-pixels=22500"`
  - (2) 마스크: `STRICT_FLAG: "--strict --ignore-rect=28,16,593,198"` (옵션 구현 후)
  - (1) 러너 기준 세트: 비교 step 의 `base=project/tests/view/screenshots` 를 `…/ci` 로 바꾸고 러너 캡처 5장을 `ci/` 에 추가, `STRICT_FLAG: "--strict"`
