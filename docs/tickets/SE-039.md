## 목표

10분 플레이에 필요한 화면 전부를 이벤트 구독 + 명령 발행만으로 만든다. 상단 HUD(현금·명성·N일차·구간·배속 버튼 0/1/2/3 — 구간 허용 밖은 비활성), 섭외 패널(12명 목록: 이름·장르·등급·인기·개런티·바이오, 잠김 표시, "섭외" → `artist.book_requested`), 티켓 가격 스피너(낮 구간만, 5~40), 마감 리포트(`economy.day_settled` + `show.ended` + `reputation.changed` 합성: 매출·비용·순이익·관객·만족 등급·명성 Δ, "다음 날" → `time.next_day_requested`), 구제 제안 모달(`bailout_offered` → "수락" → `economy.bailout_accept_requested`), 파산 화면(`economy.bankrupt` → "새 게임"), 티어 2 해금 토스트(`tier_unlocked` — "계속 플레이"), 우측 알림 피드(`build.rejected`·`artist.booking_rejected`·`economy.ticket_price_rejected` 등 reason 문자열), 메뉴(Esc: 저장/불러오기 슬롯 3·새 게임 — `session.*` 명령).

1. 불러오기 뒤 현금: `session.loaded` 에 `cash` 가 없고 `economy.cash_changed` 도 재발행 안 함(SE-036 AC6). 추천 — economy 읽기 멤버(`cash`)를 SE-040 인계 목록에 추가(명성 `total` 과 같은 규약). 1차는 새 게임 `starting_cash` 만.
2. Esc 충돌: 메뉴는 Godot 기본 액션 `ui_cancel`, 배치 취소 `build_cancel` 도 Esc. 추천 — SE-040 에서 고스트가 있으면 `build_cancel` 이 먼저 소비(현재 `_unhandled_input` 순서 확인), 필요하면 `InputActions` 에 `menu_toggle` 추가(view/input — render-engineer 후속).
3. AC7 예외 2파일(`build_palette.gd`·`debug_hud.gd`): `ui_ko.json` 이 들어온 뒤 같은 문장으로 키 전환하면 캡처 불변. 추천 — 2차 병합 뒤 후속 티켓 1건.
4. 저장 슬롯 수·새 게임 시드·리포트 순서는 `ui_params.tres`(표시 상수)에 뒀다. 추천 — 슬롯 수는 SE-036 `save.json` 이 생기면 그쪽으로, 시드는 SE-040 이 정한다.
5. 메뉴를 열 때 일시정지(`time.speed_requested {0}`)는 하지 않았다. 추천 — 그대로(PRD 에 규칙 없음), 플레이 판단은 사람.
6. R12 진행도는 `tiers.json` 을 직접 읽는다(`ReputationConfig.tier_threshold()` 와 같은 출처). 해금 뒤 기준 티어는 `ReputationSystem.unlocked_tier` 또는 `tier_unlocked` 수신으로 올린다.
