## 목표

현재 외곽선은 역면 헐(`outline.gdshader`, `cull_front` + 법선 방향 밀기, `next_pass`)이라 각진 BoxMesh 에서 면 법선이 갈라져 (1) 모서리에 1~2px 틈, (2) 설정 2px 가 바·무대 수직 모서리에서 1px 로 가늘어짐(qa 측정: 바 카운터 수직 모서리 y 510~639 폭 1, 무대 모서리 2), (3) 바닥과 닿는 아랫변은 헐이 바닥에 가려 외곽선이 거의 없음.
포스트프로세스(스크린스페이스) 외곽선 패스를 **새 시안 id `ss`** 로 추가해 같은 장면·같은 캡처 명령으로 역면 헐(B)과 나란히 비교하고, 비용(primitives·draw calls, Xvfb 무효 측정)을 표로 남긴다. **기본값(B)은 바꾸지 않는다** — 룩 변경이라 채택은 사람(아트 디렉터)의 스크린샷 승인 사항이며, 비용 실측(M1)은 다음 사람 관문 때 다른 측정과 묶는다.

### 검출 방식(Compatibility 제약 확인 결과)

- **gl_compatibility 에서 깊이 텍스처 접근 가능**(Godot 4.7.2, Mesa llvmpipe OpenGL 4.5 확인): `hint_depth_texture` 샘플러를 투명 패스 머티리얼(ALPHA 사용)에서 읽으면 불투명 패스 깊이가 들어온다. `hint_normal_roughness_texture` 는 forward_plus 전용이라 **쓰지 않았다**(AC7 텍스트 검사 0건). NDC 는 `#if CURRENT_RENDERER == RENDERER_COMPATIBILITY` 로 분기(OpenGL 깊이 [-1,1], RD [0,1]). `hint_screen_texture` 는 쓰지 않는다(색 합성은 blend_mix).
- 깊이는 화면 px 단위로 바꾼다(직교: px/m = |P[1][1]|·VIEWPORT_SIZE.y/2) → 임계값이 줌과 무관.
- 판정(이웃 = 반지름 `outline_px` 원판): (1) 깊이 불연속 — 이웃이 `depth_threshold_px` 넘게 앞이면 먼 쪽(실루엣 바깥)을 칠한다 → B 처럼 선이 물체 바깥에 붙는다. (2) 법선 불연속(주름) — 깊이가 이어지고, 이웃이 내 접평면에서 `plane_epsilon_px` 넘게 벗어나고, 법선 내적 < `normal_threshold` 이면 카메라를 덜 향한 면(바닥)을 칠한다. 대칭 주름(박스 가운데 수직 모서리)은 한쪽만.
- 법선은 깊이에서 재구성: 축마다 양쪽 3 px, 한쪽 쌍 6후보 중 중심 외삽 오차 최소의 기울기. 두 축 오차가 `normal_fit_px` 이하일 때만 법선을 믿는다. 이것 없이는 바닥 격자선(0.005 m 위 1 px 선, 줌 0 에서 깊이 1.5~3.4 px 단차)이 교차점마다 점 잡음을 만든다(초기 시안: 바닥 300×1200 영역 399 px → 최종 0 px).
- 박스 모든 모서리(윗면 앞 모서리·가운데 수직 모서리 포함)에 선이 생긴다. B 는 내부 주름에 선이 없다 — 룩 차이(아트 디렉터 판단 대상).
- 바닥 슬래브 가장자리(그리드 끝)도 실루엣이라 선이 생긴다(배경이 어두워 거의 안 보임).
