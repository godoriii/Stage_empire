## 목표

현재 외곽선은 역면 헐(`outline.gdshader`, `cull_front` + 법선 방향 밀기, `next_pass`)이라 각진 BoxMesh 에서 면 법선이 갈라져 (1) 모서리에 1~2px 틈, (2) 설정 2px 가 바·무대 수직 모서리에서 1px 로 가늘어짐(qa 측정: 바 카운터 수직 모서리 y 510~639 폭 1, 무대 모서리 2), (3) 바닥과 닿는 아랫변은 헐이 바닥에 가려 외곽선이 거의 없음.
포스트프로세스(스크린스페이스) 외곽선 패스를 **새 시안 id `ss`** 로 추가해 같은 장면·같은 캡처 명령으로 역면 헐(B)과 나란히 비교하고, 비용(primitives·draw calls, Xvfb 무효 측정)을 표로 남긴다. **기본값(B)은 바꾸지 않는다** — 룩 변경이라 채택은 사람(아트 디렉터)의 스크린샷 승인 사항이며, 비용 실측(M1)은 다음 사람 관문 때 다른 측정과 묶는다.

## 범위

- 포함:
  - 시안 id `ss`: `ShaderVariants.IDS` 에 추가(`SELECTABLE_IDS` 는 그대로 a/b/c — 키 4 는 할당하지 않음). 머티리얼 `params/toon_ss.tres` = `toon_b.tres` 와 동일 파라미터이되 `next_pass` 없음. 외곽선은 씬에 1개 붙는 포스트 패스(`project/view/shaders/outline_ss.gdshader` + 적용 노드: 전체 화면 쿼드 `MeshInstance3D`(QuadMesh, `render_priority` 뒤, 깊이 텍스처) 또는 `CanvasLayer` 셰이더 — 방식은 구현자 선택, 아래 AC 로만 판정). `ShaderVariants.apply(root, "ss")` 가 포스트 패스 노드를 **정확히 1개** 추가하고 다른 id 로 되돌리면 제거한다(노드 수 복원).
  - 외곽선 검출: 깊이 불연속 + 법선 불연속. forward_plus 와 gl_compatibility(Xvfb·CI) **둘 다**에서 동작해야 한다 — compatibility 에 `hint_normal_roughness_texture` 가 없으므로 법선은 깊이 미분(dFdx/dFdy)으로 재구성하거나 깊이만 쓰되, 바닥 접점(깊이 연속·법선 불연속)이 보여야 한다(AC2). 두께 `outline_px`·색 `outline_color` 는 `params/outline_ss.tres` 에(B 와 같은 2px·같은 색), 깊이·법선 임계값도 `.tres` uniform(코드 리터럴 0 — SE-004 AC3 테스트 유지).
  - 캡슐(캐릭터)은 `ss` 에서도 외곽선 폭이 B 와 같아야 한다(AC3). 군중 MultiMesh 5,000 에 `ss` 를 적용했을 때 외곽선 `next_pass` 가 없으므로 primitives ≈ plain(×1.0) + 쿼드.
  - 캡처: `project/tests/view/screenshots/SE-021/ss_yaw45_zoom2.png`, `ss_yaw45_zoom0.png`(SE-004 b 캡처와 같은 명령, `--material=ss`). 비교용 `b_*` 는 SE-004 폴더의 것을 그대로 쓴다.
  - 비용: `measure_spike.tscn -- --config=E --material=ss` 가 돈다(JSON `material == "ss"`). Xvfb 무효 측정으로 `primitives`·`draw calls` 를 `results/SE-021.md` 에 plain/b/ss 3행으로(유효 fps 는 사람 실측 대기 행).
  - 테스트: `test_shader_variants.gd`(ss 적용/해제 노드 수), `test_toon_shader.gd`(ss uniform 전부 `.tres` 명시, 코드 리터럴 0), `test_se021_outline_qa.gd`(아래 AC1~AC3 픽셀 측정, SE-004 qa 테스트와 같은 방법·좌표 표), `test_measure_spike.gd`(ss JSON).
- 제외(다른 티켓):
  - `ss` 를 기본값으로 채택 — 사람 결정(status 질문 Q2: B 유지 / ss 채택 / 수정). 채택되면 SE-018 과 같은 꼴의 후속 티켓.
  - M1·dGPU 실측 — 사람, 다음 관문 때 묶음(`SE-021-E-ss.json`).
  - 역면 헐 제거·`outline.gdshader` 변경 — 없음(B 는 그대로 비교 기준).
  - 군중 접지감(블롭 그림자·AO) — 별도 룩 티켓.
