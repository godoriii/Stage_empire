## 목표

플레이어가 낮 구간에 오늘 공연할 아티스트를 섭외하고(개런티 선지급), 공연 뒤 그 아티스트가 성장하는 루프의 규칙과 12명 명단을 만든다. v0 는 등급 2단계(local/rookie)와 성장(인기·실력 정수 증가, 등급 승급 1회)까지. 관계도·라이더·타 베뉴 유출은 필드만 예약하고 규칙은 버티컬 슬라이스로.

## 범위

- 포함(1차, game-designer):
  - `docs/gdd/artist.md`: 상태(`roster: [{id, grade, popularity, skill, shows_played, discovered_here, relationship}]`, `lineup_today: id|null`, `booked_days`), 섭외 규칙 K1~Kn: 낮 구간에서만(`artist.book_requested {artist_id}` 명령), 하루 1명(v0), 등급 가용(local 항상, rookie 는 명성 임계 — reputation.md 와 같은 값), 개런티 = `guarantee_by_grade[grade]`(v0 경제 테이블 값 그대로; 동적 개런티는 필드 예약) → `economy.charge_proposed {reason:"guarantee"}` → 승인이면 `artist.booked {day, artist_id, guarantee}`, 거절이면 `artist.booking_rejected {artist_id, reason: "not_allowed"|"already_booked"|"grade_locked"|"insufficient_cash"|"unknown_artist"}`; 취소 명령은 v0 없음(결정 로그). 라인업 이벤트 `artist.lineup_set {day, artist_id|null}`(저녁 진입 틱 — audience/show 입력). 성장: `show.ended` 구독 → 등급별 `popularity += Δ(grade)`, `skill += Δ`, `shows_played += 1`, 승급 조건(local → rookie: popularity ≥ 임계) → `artist.grown {artist_id, popularity, skill, grade, promoted: bool}`. 휴식(연속 공연 피로)은 v0 없음. 스냅샷(정수·문자열만), 난수 없음(성장 v0 는 결정적; `artist` 스트림 예약).
  - `project/data/schemas/artists.schema.json`(id `^[a-z0-9_]+$`, name, genre ∈ genres id, grade ∈ {local, rookie, midlevel, headliner, legend}, popularity 0~100, skill 0~100, personality 태그 배열, rider 빈 배열 허용, bio_key(텍스트 키)) + `project/data/artists/artists.json` 의 **구조 예시 2행**(content-writer 가 12행으로 교체), `project/data/artist/artist.json`(성장 Δ·승급 임계·등급 가용 임계) + 스키마.
  - `events.md` 에 `artist.*` 5행(`book_requested`, `booked`, `booking_rejected`, `lineup_set`, `grown`).
  - 수용 기준 AR1~ARn(섭외 성공/거절 5종, 라인업 없는 날, 성장·승급, 스냅샷 왕복).
  - content-writer 에게 넘길 명단 조건: 12명 = MVP 3장르 × 4명, 등급 local 8 / rookie 4, 인기·실력 분포 표(겹치지 않게), 이름·바이오 규칙(실존 연상 금지, 한국어, 바이오 2문장 ≤ 120자, 성격 태그 2개).
- 포함(2차, content-writer): `artists.json` 12행(1차 분포 표대로 수치 채움 — 수치 변경 아님, 1차가 정한 값 배정), `project/data/text/artists_ko.json`(`{bio_key: 문장}`) + 스키마가 없으면 1차가 `text.schema.json` 을 미리 만든다. 실존 아티스트·밴드·곡명 연상 검사(결과 절에 자기 검토 표).
- 제외(다른 티켓): 구현(SE-033), 섭외 UI(SE-039), 관계 이벤트·라이더·유출·발굴 보너스 규칙(버티컬 슬라이스), 초상(VS).
