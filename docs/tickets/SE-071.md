## 목표

프로덕트 오너 요청(2026-10-20): "음악 테마는 직접 고를 수 있으면 좋겠다". 테마를 준비 단계의 결정으로 바꾸되, 늘 헤드라이너 장르를 고르는 게 정답이 되지 않도록 트렌드와 오프닝 장르로 긴장을 남긴다.

## 규칙 (추천안 채택)

- 제안 카드의 랜덤 `theme` → 랜덤 `trend`(요즘 뜨는 장르). RNG 호출 순서·횟수는 그대로.
- 준비 기둥 0에 **테마 장르** 선택(4장르 중 1, 필수).
- 헤드라이너 장르 = 테마: 수요 +20 %, 만족 +3 (기존 그대로).
- 테마 = 트렌드: 수요 +10 % (`balance.demand.trend_demand_pct`).
- 오프닝 장르 ≠ 테마: 오프닝 1팀당 만족 −2 (`balance.lines.opener_off_theme`), 오프닝 구간에 실현.

## 수용 기준

- [ ] AC1. run.md·show.md·README 가 위 규칙으로 고쳐지고, 손 계산 예시 (a)(b) 숫자가 새 규칙에서도 성립(테마 = 기존 테마, 트렌드 불일치)하거나 갱신된다.
- [ ] AC2. 엔진이 plan.theme 없으면 계획을 거부하고, 위 세 효과를 적용한다. 테스트 추가.
- [ ] AC3. 봇: 무작위는 테마 균등, 합리적은 테마 = 헤드라이너 장르(트렌드 동점 우대). 1막 통과율이 목표(무작위 20~50 %, 합리적 70~90 %) 안.
- [ ] AC4. 프로토타입 준비 화면에 테마 선택, 제안 카드에 트렌드 표시, 경고·리뷰 문구 반영.
