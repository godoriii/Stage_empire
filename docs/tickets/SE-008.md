## 목표

SE-001 구현(`EventBus.publish()`가 `*_requested` 페이로드의 float 를 정수값이어도 거부)이 tick.md v0·events.md·economy.md 와 어긋난다.
reviewer(docs/reviews/SE-001.md 발견 1)가 **스펙을 구현에 맞추는 (a)안**을 채택했다. 근거: float 허용은 JSON 왕복·복원 후 상태 해시 동일 규칙(tick.md 스냅샷 절)과 자기모순이고, 강한 계약을 먼저 병합하고 완화하는 순서가 안전하다.
이 티켓이 닫히기 전에는 economy 구현 티켓을 내지 않는다(economy.md 의 25.0 허용 문장을 그대로 구현하면 EC13 이 실패).

## 범위

- 포함: tick.md, events.md, economy.md 의 문장 수정과 변경 이력. SE-001 결과 절·docs/reviews/SE-001.md 발견 1·2 의 내용 반영.
- 제외(다른 티켓): core/tests 코드 변경 0 (코드는 이미 맞다). SE-007-bug(별도).
