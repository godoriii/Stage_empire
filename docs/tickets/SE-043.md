## 목표

MVP 관문. 사람 5명(프로덕트 오너 포함 내부)이 각자 10분 플레이한 뒤 "한 번 더" 여부를 답한다. producer 는 빌드 방법·시나리오·질문지를 준비하고 결과를 `docs/status/` 에 기록, 다음 마일스톤(버티컬 슬라이스) 착수 또는 루프 재설계 티켓을 발행한다. 같은 자리에서 검수 큐 에셋 5개의 승인/반려(아트 디렉션)도 받는다(선택 — 미승인이면 프록시 메시로 계속).

## 범위

- 포함(producer): 플레이 테스트 안내 1쪽(`docs/status/` 다음 주차 파일에 절로): 실행 명령(`godot --path project res://view/scenes/main.tscn`, Godot 4.7.2, `git lfs pull`), 시드 안내(각자 다른 시드 5개 지정), 10분 타이머, 조작 요약(팔레트·섭외·배속·마감), 질문 5개(① 한 번 더 하고 싶은가 예/아니오 ② 가장 재미있던 순간 ③ 가장 답답했던 순간 ④ 10분 동안 몇 일차까지 갔나 ⑤ 다음에 하고 싶은 것), 봇 통계 요약 표(SE-042) 첨부. 결과 집계(5명 중 "한 번 더" 수, 자유 응답 묶음) → 결정 로그 + 후속 티켓 후보 표.
- 포함(사람): 플레이 5회, 답변 5장, 검수 큐 승인/반려(선택), 관문 판정(통과 기준: **5명 중 4명 이상 "한 번 더"** — PRD 가 수치를 정하지 않았으므로 producer 추천값, 결정 로그).
- 제외(다른 티켓): 외부 테스터(VS), 설문 도구, 트레일러.
