## 목표

`safe_remove_work` 가 `$TMPDIR` 기반 사본을 거부해(`/tmp`·`SE_MUTATE_DIR` 만 허용) macOS(`/private/tmp`)·`TMPDIR` 설정 환경에서 사본이 매번 남는 문제, `SE_MUTATE_DIR` 가 리포지토리 안이어도 사본을 만들어 untracked 잔여가 생기는 문제(SE-016 `_mut_tmp` 재발 경로)를 닫는다. 가드를 "실경로 `$BASE/se_mutate.?*` 하나" 로 단순화한다.

## 범위

- 포함: `tools/bot/mutate_and_test.sh` — `:62` 에서 실경로로 만든 `$BASE` 를 보관하고 `safe_remove_work` 판정을 `case "$w" in "$BASE"/se_mutate.?*) ok=1` 하나로(리포지토리 밖·이름 조건 유지); `:62` 뒤 `case "$BASE" in "$ROOT"|"$ROOT"/*) … exit 2` 추가; `#` 주석만 있는 패치 파일 처리(README 에 "빈 패치 = 0 바이트만" 명시 **또는** `grep -q '^@@'` 로 빈 패치 취급 — 택일, 결과 절에 기록). `tools/bot/README.md` 환경 변수 절 "리포지토리 밖" 1줄, exit 2 설명에 "알 수 없는 옵션/인자 초과/`..`·절대 경로" 보강, `git diff --no-index` 예시에 `--src-prefix=a/ --dst-prefix=b/` 1줄.
- 제외(다른 티켓): 예시 패치 2개(`mutations/*.diff`) 변경 — 현 `economy.gd` 와 일치하므로 손대지 않는다. shellcheck CI 단계 — 별도.
