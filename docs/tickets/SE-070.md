# SE-070 v2 브라우저 프로토타입 (1막)

| 항목 | 값 |
|---|---|
| 상태 | 리뷰 |
| 담당 에이전트 | producer(메인 세션 직접 구현) |
| 마일스톤 | 프리프로덕션 (v2) |
| 의존 티켓 | SE-069 |
| 브랜치 | feature/SE-070-v2-web-proto |

## 목표

설치 없이 휴대폰 브라우저에서 1막(클럽 3공연 + 결산 쇼케이스)을 끝까지 플레이할 수 있다. 확인할 질문: "한 막을 끝내고 바로 다시 런을 돌리고 싶은가?"

## 수용 기준

- [x] AC1. 제안 → 준비(예상치 미리보기·위험 경고) → 개최(배속 자동 진행 + 돌발 카드) → 결과(원인 분해) → 보상 카드 3택1 → 다음 공연이 끊김 없이 돈다.
- [x] AC2. 런 실패/막 통과/새 런 시작이 된다.
- [x] AC3. 엔진은 SE-069 모듈 그대로 사용(규칙 중복 구현 없음).
- [x] AC4. 휴대폰 폭(375px)에서 가로 스크롤 없이 플레이 가능.

## 테스트 방법

- 프로덕트 오너 플레이 1~2회 + 메인 세션 헤드리스 브라우저 클릭 스모크.

## 결과

- 파일: `prototype/v2/web/{app.js,style.css,template.html,build.mjs,smoke.mjs}`. `node prototype/v2/web/build.mjs` 가 engine.js + app.js + CSS + 데이터 JSON 을 HTML 한 파일(`web/dist/`, gitignore)로 묶는다. 규칙 코드는 engine.js 하나(AC3).
- 게시: 비공개 Artifact https://claude.ai/artifact/4owwLzYShuh47gQMeeGAR5 (프로덕트 오너 플레이용).
- 스모크: `NODE_PATH=$(npm root -g) node prototype/v2/web/smoke.mjs <built.html> "" 3` — 375px 라이트 3런(시드 12345 → 같은 시드로 다시 → 새 시드) + 1280px 다크 1런(시드 12345). 원시 출력:
