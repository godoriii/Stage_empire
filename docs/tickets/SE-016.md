## 목표

(1) 파산 뒤 `Economy` 가 `time.*` 를 통째로 무시해 `economy.day`·`phase` 가 파산일 close 에 고정된다(`economy.gd:316`·`:334`). economy.md `:258` "모든 입력을 무시" 글자 그대로라 구현 문제는 아니지만, #상태 표는 `day`·`phase` 를 "따라온 현재 날/구간"으로 정의하고 `ticket_price_rejected.phase` 가 파산 뒤 실제 구간과 다른 값을 싣는다.
**producer 결정(2026-10-09, 결정 로그): reviewer 추천안 (a) 채택 — 파산 뒤에도 `day`·`phase` 추적은 유지하고 경제 동작(지출·환불·매출·유지비·정산·구제·가격)만 무시한다.** 구현 2줄, `reference_scenarios` 기대값·리플레이 기준값 불변.
(2) 공개 API 표에 없는 멤버(`EconomyConfig.has_row/scenario/as_int`, `Economy.split_installments`, `EventBus.is_valid_value`)를 표에 올린다. 코드 문제 아님.

## 범위

- 포함(1차, game-designer):
  - `docs/gdd/economy.md` "파산 뒤" 문단(`:258`): "`bankrupt == true` 면 economy 는 **경제 입력**을 무시한다(지출 C1 거절, 환불·매출·유지비 보고 무시, 정산 없음, 티켓 가격 `not_allowed`, 구제 없음). **`time.day_started`·`time.phase_changed` 의 `day`·`phase` 추적은 유지**한다(#상태 표의 정의 그대로. 게임 오버 UI·`ticket_price_rejected.phase` 가 현재 구간을 본다). 정산·S0·자동 수락은 하지 않는다." 로 고친다. #상태 표(`:44-45`)와 모순 0.
  - EC12 행(`:462`)에 "파산 뒤 `time.*` 를 더 보내면 `day`·`phase` 는 따라오고 그 외 상태는 불변, 이벤트는 `charge_resolved(bankrupt)`·`ticket_price_rejected(not_allowed, phase = 현재 구간)` 뿐" 추가.
  - 공개 API 표(`:313-320`)에 행 추가: `EconomyConfig.has_row(tier: int) -> bool`, `scenario(id: String) -> Dictionary`(없는 id 면 `push_error`, `{}` — 구현 확인해 적는다), `static as_int(v: Variant) -> Variant`(정수값 `float`→`int`, 아니면 `null`), 상수 `START_TIER`·`LEDGER_ADMISSIONS/AUDIENCE/GUARANTEE`·`LEDGER_KEYS`(`economy_config.gd:11-28`); `Economy.static split_installments(total: int, n: int) -> Array`(R5, `economy.gd:198`).

  - 두 문서 변경 이력 행 1개씩(SE-016).
- 포함(2차, sim-engineer):
  - `project/sim/economy.gd` `_on_phase_changed`(`:314-317`)·`_on_day_started`(`:332-335`): `bankrupt` 검사 **앞**에서(또는 검사 안에서) `day`·`phase` 만 갱신하고 return. 정산·S0·자동 수락·`pending_bailout` 처리는 계속 건너뛴다. 기대 diff ≈ 2~4줄.
  - `project/tests/sim/test_economy.gd` EC12 `test_bankrupt_after_bailouts_exhausted`(`:686-702`): "파산 뒤 상태 불변" 해시 단언을 "`day`·`phase` 를 뺀 스냅샷 불변 + `day == 15`, `phase == "close"`"로 바꾸고, `ticket_price_rejected.phase` 기대값이 요청 시점 구간(현재 코드 순서상 파산일 `"close"`)과 같음을 리터럴로 단언 1개 추가. 파산 뒤 `time.*` 를 더 보냈을 때 `day_settled`·`bailout_*`·`cash_changed` 0 유지.
