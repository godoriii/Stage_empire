## 목표

(1) 파산 뒤 `Economy` 가 `time.*` 를 통째로 무시해 `economy.day`·`phase` 가 파산일 close 에 고정된다(`economy.gd:316`·`:334`). economy.md `:258` "모든 입력을 무시" 글자 그대로라 구현 문제는 아니지만, #상태 표는 `day`·`phase` 를 "따라온 현재 날/구간"으로 정의하고 `ticket_price_rejected.phase` 가 파산 뒤 실제 구간과 다른 값을 싣는다.
**producer 결정(2026-10-09, 결정 로그): reviewer 추천안 (a) 채택 — 파산 뒤에도 `day`·`phase` 추적은 유지하고 경제 동작(지출·환불·매출·유지비·정산·구제·가격)만 무시한다.** 구현 2줄, `reference_scenarios` 기대값·리플레이 기준값 불변.
(2) 공개 API 표에 없는 멤버(`EconomyConfig.has_row/scenario/as_int`, `Economy.split_installments`, `EventBus.is_valid_value`)를 표에 올린다. 코드 문제 아님.
