## 목표

`build.place_requested`/`build.demolish_requested` 명령을 받아 맵·가구 데이터로 유효성을 판정하고 economy 와 핸드셰이크한 뒤 `build.placed`/`build.rejected`/`build.demolished`/`build.coverage_changed`/`economy.upkeep_reported` 를 내는 순수 데이터 시스템. 관객(SE-034)이 쓸 타일 경로 탐색(점유 타일 차단, 입구 → 목표 타일)도 `world/` 에 둔다. Node·Scene API 0.

## 범위

- 포함:
  - `project/world/furniture_config.gd`(`FurnitureConfig`: `furniture.json` 로드·교차 검사 — id 유일, `footprint` ≥ 1, 유지비 < 환불 잔여 규칙), `project/world/map_config.gd`(`MapConfig`: `tier1_club.json` — 벽·입구·크기), `project/world/build_system.gd`(`BuildSystem`: 상태·명령 핸들러·핸드셰이크·커버리지 재계산·스냅샷 훅), `project/world/grid_occupancy.gd`(`GridOccupancy`: 점유·회전된 풋프린트 셀 계산), `project/world/coverage.gd`(`Coverage`: 정적 순수 함수 — 음향·시야·바·수용·피난), `project/world/tile_path.gd`(`TilePath`: `AStarGrid2D` 래퍼(RefCounted, Node 아님) — 점유 갱신·경로 질의; 결정적 — 같은 입력 같은 경로, 대각 이동 금지 v0). 각 `.gd` 마다 `project/tests/sim/test_<이름>.gd`.
  - `TickLoop.register_system("build", update, snapshot, restore)` — `update` 는 no-op(낮 구간 명령만), 핸드셰이크는 명령 핸들러 안에서 E2 FIFO 로.
  - 수용 기준 BC1~BCn(SE-028) 전부 테스트로. 기준 배치 2개의 커버리지·수용·유지비 리터럴 단언.
  - 경계 테스트: `test_core_boundary.gd` 와 같은 방식으로 `project/world/**/*.gd` 에 `extends Node`·`_process(`·`get_node(`·`Time.`·`randi(` 0건(`AStarGrid2D` 는 허용 목록에 명시).
- 제외(다른 티켓): 렌더·UI(SE-037), 관객 이동 로직(SE-034 — `TilePath` 만 제공), 스태프 구역, 방 드래그, 맵 편집.
