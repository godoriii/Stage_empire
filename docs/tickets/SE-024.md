## 목표

materials.md 채택안 (b)(슬롯 = 서피스)에 맞춰 `toon.gdshader` 가 정점 알파를 의미 채널로 읽는 마지막 코드(`:40-42`)를 지운다. 화면 픽셀은 한 장도 바뀌지 않아야 한다(현 `.tres` 의 `accent_color` 가 흰색이고 모든 인스턴스 알파가 1 이라 수학적으로 동일). 같은 `view/` 파일군을 만지는 SE-018 후속 A(시안 `.tres` 로드 실패 때 측정기가 "라벨은 b, 실제 룩은 plain" 인 결과를 내는 문제)를 한 브랜치로 묶는다.

## 범위

- 포함:
  - (R-A) `project/view/shaders/toon.gdshader:40-41` 삭제, `:42` → `ALBEDO = base_color.rgb * COLOR.rgb;`, `:5-7` 머리 주석을 "슬롯 = 서피스(docs/gdd/materials.md), 정점 알파 무의미, COLOR.rgb 는 base 서피스에만 곱한다" 로 교체. `:29` `accent_color` uniform 은 **유지**하고 그 줄 주석에 "R-B(SE-041 2차)에서 accent 서피스 색으로 씀 — 미사용이지만 `.tres` 3개 변경을 피하려 둔다" 1줄(reviewer SE-019 참고 항목 — R-A 리뷰에서 죽은 코드로 반복 지적되지 않게).
  - (R-A 테스트) `project/tests/view/test_toon_shader.gd` 에 정규식 `\bCOLOR\s*\.\s*a\b` 매치 0 단언 + 대조군 1건(그 문자열을 넣은 소스 문자열은 매치).
  - (후속 A) `project/tests/view/perf/measure_spike.gd` `_spawn_spike()`: `add_child(spike)` 뒤 `spike.material_id != ShaderVariants.PLAIN_ID and spike.crowd.material_override == null` 이면 `push_error` + `EXIT_BAD_SETUP`(JSON 파일 생성 없음). `run_issues`·`gate_verdict`·`REQUIRED_KEYS`·`SE013_KEYS`·`build_report` 본문 불변.

  - (후속 A) `project/view/scenes/grid_sandbox.gd:67-68`(`apply < 0 → false`) 분기 테스트 1건(`ShaderVariants.apply` 를 잘못된 `path_pattern` 으로 부른 뒤 `material_override` 검사, 또는 스파이크에 `material_path_pattern` 주입 — 구현자가 택하고 결과 절에 기록).
  - (후속 A) `project/view/scenes/shader_placeholders.gd:7,72` 주석 "default 시안" → "plain 시안".
