## 목표

플레이어가 하단 팔레트에서 가구를 고르고, 타일 위에 고스트(유효 = 녹색, 무효 = 빨강)를 보며 클릭으로 `build.place_requested` 를 보내고, `build.placed` 를 받아 가구 메시가 그리드에 서는 것까지. 철거 모드(클릭 → `build.demolish_requested`), 회전 R, 취소 Esc, 오버레이 키 1개(음향/시야/바 서비스 순환, `build.coverage_changed` 데이터로 타일 색 데칼). 에셋이 없는 가구는 풋프린트 × 높이 BoxMesh 프록시(슬롯 `base` 색) — SE-041 에셋이 들어오면 메시만 교체되는 구조.

## 범위

- 포함: `project/view/build/furniture_view.gd`(`FurnitureView`: `build.placed/demolished` 구독 → 인스턴스 노드 생성·삭제, 프록시 또는 `res://assets/models/<id>.glb` 존재 시 로드, 회전, 시안 적용), `project/view/build/placement_ghost.gd`(고스트·유효성 미리보기 — 유효성은 **view 쪽 추정**(맵 밖·점유 겹침·벽 인접만, 자금은 sim 판정) 으로 색만, 최종은 sim 의 `placed/rejected`), `project/view/build/coverage_overlay.gd`(타일 데칼 — `MultiMesh` 평면 또는 `GridView` 색 채널), `project/ui/build/build_palette.gd` + `.tscn`(하단 팔레트: 카테고리 탭 7, 가구 버튼 20, 비용·유지비 표시, 철거 버튼), 입력 액션 추가(`build_rotate`=R, `build_cancel`=Esc, `overlay_cycle`=O, `build_demolish`=X — `InputActions` 런타임 등록, `project.godot` 편집은 사람 C2 와 같은 방식), `build.rejected {reason}` 토스트(간단 Label 3초). 테스트 `project/tests/view/test_furniture_view.gd`, `test_placement_ghost.gd`, `test_build_palette.gd`, `test_coverage_overlay.gd`(가짜 버스로 이벤트 주입 → 노드 트리 단언), 캡처 1장 `screenshots/SE-037/build_baseline_yaw45_zoom2.png`(기준 배치 2 + 오버레이 음향, 샌드박스 `--se-build-preset=baseline` 인자).
- 제외(다른 티켓): sim 판정(SE-032), HUD 자금 표시(SE-039), 실제 에셋(SE-041), 방 드래그, 카메라 벽 컷어웨이(VS).
