# SE-055 결제 응답 `charge_resolved.amount` 이상값 규칙 — artist·build 같은 문장으로

| 항목 | 값 |

| 담당 에이전트 | game-designer (artist.md·build.md H2 한 문장) → sim-engineer (두 시스템 구현 + 테스트) → qa |
| 마일스톤 | MVP |

| 브랜치 | feature/SE-055-charge-amount-rule |

## 목표

`economy.charge_resolved.amount` 가 0 이상 정수가 아닐 때의 처리가 artist·build 스펙에 없다. 지금은 economy C2 가 음수를 `invalid` 로 거절해 도달하지 않지만, 두 시스템이 같은 규약을 갖게 한 문장으로 정하고 구현한다.

## 범위

- 포함(game-designer): artist.md·build.md H2 에 같은 문장 "amount 가 0 이상 정수가 아니면 push_warning 1회 후 제안액을 쓴다"(또는 더 나은 추천안 — 결정 로그).
- 포함(sim-engineer): `project/sim/artist_system.gd`(약 208행)·`project/world/build_system.gd`(약 184행) 를 그 문장대로. 시스템마다 `amount: -1` 테스트 1건.
- 포함(qa): `test_artist_qa.gd` 미사용 `const ARTIST_MD` 정리(사용하거나 삭제), `_min_of`·`_max_of` 첫 원소 초기화(SE-046 리뷰 낮음).
- 제외: economy 규칙 변경.
