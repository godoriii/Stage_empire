## 목표

tick.md restore 3단계가 확정한 두 거부 조건(I4 위반, `seed` 범위 밖)이 구현(`project/core/tick.gd` `restore()`)에는 있지만 테스트에는 없다
(docs/reviews/SE-008.md 발견 1, docs/tickets/SE-008.md 남은 질문 1). 기존 케이스 `test_tick.gd::test_restore_rejects_bad_snapshot`에
불량 스냅샷 3종과 경계값 통과 1종을 더해 스펙 문장이 테스트 없이 서 있는 상태를 없애고, tick.md AC10 행과 변경 이력(SE-007 S4 포화 행,
docs/reviews/SE-007.md 발견 1)을 코드와 맞춘다. **코드(`project/core/`) 변경 0 을 기대한다.** 테스트를 추가했더니 코드가 틀렸다면 고치지 말고 결과 절에 적어 producer 에게 돌려보낸다(새 티켓).
