# 아트 스타일 가이드 (초안)

아트 디렉터(사람)가 확정한다. 아래는 PRD에서 이미 정해진 규칙과, 프리프로덕션에서 채워야 할 빈칸이다.
art-pipeline, render-engineer, audio 가 이 문서를 기준으로 일한다.

## 결정된 것 (PRD)

- 룩: 3D 로우폴리 + 플랫 컬러 머티리얼 + 툰 셰이더 + 외곽선 패스. 사실적 텍스처 금지.
- 카메라: 직교, 피치 약 30°, 요 45°, 90° 단위 4방향 회전, 줌 4단계. 모델 1개가 전 각도를 커버한다.
- 그리드: 1타일 = 1m. 모든 오브젝트는 타일에 스냅. 피벗은 **바닥 중심**(타일 점유 영역의 중앙, y=0).
- 실내 티어는 카메라 쪽 벽 컷어웨이. 야외 티어는 높이맵 지형.
- 조명이 핵심 매력: 스포트라이트, 무빙 헤드, 레이저, 안개 볼륨, LED 월은 실제 3D 라이트 + 파티클.
- 그림자: 무대·가구·스태프만 그림자를 드리운다. **관객 군중은 그림자를 드리우지 않는다**(2026-10-09 결정, SE-003 셰도우 패스 비용). 군중의 입체감은 라이트 색·조도와 앰비언트 오클루전 근사로 낸다.
- 실존 브랜드·로고·아티스트 연상 요소 금지.

## 프리프로덕션에서 확정할 것

| 항목 | 후보/기준 | 상태 |
|---|---|---|
| 셰이더 시안 | 3종 비교(셀 2단계/3단계, 외곽선 두께 1px/2px, 림라이트 유무) | 미정 |
| 팔레트 | 장르별 강조색 8개 + 중립 톤 6개, 색약 팔레트 별도 | 미정 |
| 폴리곤 예산 | 가구 소형 ≤ 300 tri, 대형 설비 ≤ 1,500 tri, 캐릭터 ≤ 800 tri (인스턴싱 대상), 임포스터용 LOD1 ≤ 150 tri | 초안 |
| 머티리얼 슬롯 이름 | `base`, `accent`, `emissive`, `glass` 네 종으로 고정 — 색 변형은 슬롯 파라미터로 | 초안 |
| 타일 점유 표기 | `w×d`(x, z), 높이 m. 예: 바 카운터 3×1, 높이 1.1 | 초안 |
| 상태 변형 | 기본/켜짐/고장/철거중 — 머티리얼 또는 이미시브 변화로, 별도 메시 금지 | 초안 |
| 포맷 | glTF 2.0 (`.glb`), 단위 미터, +Y 업, -Z 전방 | 초안 |

## 생성 프롬프트 템플릿 (art-pipeline 용, 확정 전 임시)

```
low-poly <object>, flat colors, no texture, clean topology, game asset, isometric-friendly,
single mesh, origin at bottom center, fits <w>x<d> meter footprint, height <h> m, <accent color> accent
```
