## 변경 요약

1. `mutate_and_test.sh` `undo_created_dirs`: `IFS=/ read -r -a parts <<< "$rest"` 를 `readarray -d / -t parts < <(printf '%s' "$rest")` 로 교체했다. `read` 는 첫 개행에서 멈추고, `readarray -d /` 는 개행·glob 모두 건드리지 않는다. `printf '%s'` 에 끝 개행을 붙이지 않아 마지막 성분의 개행이 보존된다. `a//b`(빈 성분)는 예전과 같이 빈 성분으로 남고 끝의 `/` 는 성분을 만들지 않는다. 경로 판정·정리 범위는 바뀌지 않았다. bash 4.4+ 가 필요하다(`readarray -d` 는 4.4 부터. 이 환경은 5.2.21).
2. `test_show_reputation_data.gd`:
   - `by_indie` 삭제 + 전제 단언 추가(AC2).
   - :347-348 의 `_grade_of(6732)`/`_grade_of(5730)` 를 `aud_by[...]["expected"]["avg_satisfaction_bp_hand"]` 로 교체(AC3).
   - 순환 테스트 입력(6732/83)을 `_scenario("rotation_good_30")["show_cycle"][0]` 에서 읽는다.
3. `se030_json_mutants.py` `resolve_out`: `--out` 없이 `tempfile.gettempdir()` 가 리포지토리 안이면 `mkdtemp` 전에 exit 2. TMPDIR 이 리포 안인 재현에서 rc=2, 리포 안 잔여 디렉터리 0(`ls -A` 빈 출력).

## AC1 재현

사본 구성(리포지토리 밖, 스크래치패드): `mutate_and_test.sh` 를 복사하되 "리포 안 거부" 사전 검사(`case "$BASE_PRE" in "$ROOT"|"$ROOT"/*)` 블록)를 제거했다. 사본의 `ROOT` 는 사본 디렉터리라, `SE_MUTATE_DIR` 이 그 안이면 사후 검사(:117-)가 걸려 `undo_created_dirs` 를 탄다. 각 실행마다 `area/` 를 새로 만들고 빈 디렉터리 `area/g1x` 를 둔 뒤, cwd 를 `area/` 로 해서 실행했다. `GODOT_BIN=/bin/true`, 빈 패치. 하니스: `ac1.sh <소스 스크립트> <라벨> <스크래치>`(리포 밖, 커밋하지 않음). 사본은 `sed`/`python` 으로 만들었고 변환은 위 블록 제거 한 가지뿐이다.

| 입력 `SE_MUTATE_DIR` | SE-047 이전(`local IFS=/; parts=($rest)`) | origin/main (`IFS=/ read -a`) | 수정 후 (`readarray -d /`) |
|---|---|---|---|
| `area/g*x/a` (티켓 AC1) | g1x 남음 | g1x 남음 | g1x 남음, 만든 `g*x` 정리됨 |
| `area/[g]1x/a` (glob 이 만든 디렉터리와 안 겹치는 변형) | **g1x 삭제됨** | g1x 남음 | g1x 남음 |
| `area/$'g1x\nfoo/y'` (개행) | g1x 남음 | **g1x 삭제됨**(만든 `g1x\nfoo`, `g1x\nfoo/y` 도 정리 안 되고 남음) | g1x 남음, area 에는 `g1x` 만 남음 |

참고: `g*x/a` 는 만들어진 디렉터리 `g*x` 가 glob 에 같이 걸려 SE-047 이전 구현에서도 `g1x` 를 못 지운다. 그래서 같은 효과를 내는 `[g]1x/a` 변형 행을 추가했다. 이 행이 있어야 하니스가 glob 회귀를 실제로 잡는다는 것이 보인다. 세 구현에 대해 하니스가 잡는 것(굵게)이 서로 다르므로 하니스는 감도가 있다.

수정 후 실제 출력(발췌, `cat -A` 로 개행을 `$` 로 표시):

```
--- [after] glob
사본 상위 디렉터리의 실경로가 리포지토리 안이다 (SE_MUTATE_DIR/TMPDIR): .../ac1_after/area/g*x/a
exit=2
area after (cat -A):
  ./g1x$
RESULT: g1x 남음
--- [after] glob2
... area/[g]1x/a
exit=2
area after (cat -A):
  ./g1x$
RESULT: g1x 남음
--- [after] newline
사본 상위 디렉터리의 실경로가 리포지토리 안이다 (SE_MUTATE_DIR/TMPDIR): .../ac1_after/area/g1x
foo/y
exit=2
area after (cat -A):
  ./g1x$
RESULT: g1x 남음
```

수정 전(origin/main) 개행 행: `area after` 에 `./g1x$ foo$`, `./g1x$ foo/y$` 두 항목(만든 디렉터리가 정리되지 않고 남음)이 있고 `g1x` 는 없다 → `RESULT: g1x 삭제됨(회귀)`.
