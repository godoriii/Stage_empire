## 구현 요약

`tools/bot/mutate_and_test.sh`

- (A) 경로 판정을 전부 물리 경로로: `ROOT` 도 `cd -P`. `BASE` 에 `..` 성분이 있으면 exit 2 (`case "/$BASE/" in */../*)`). `resolve_no_create` 는 상대 경로에 `pwd -P` 를 붙이고, 존재하는 가장 가까운 상위를 `cd -P … && pwd -P` 로 풀며 `cd` 실패 시 return 1 → exit 2. 결과가 `/` 이면 exit 2, `"$ROOT"|"$ROOT"/*` 이면 exit 2 (둘 다 `mkdir` 전).
- 방어선: `mkdir -p` 뒤 `BASE="$(cd -P … && pwd -P)" || …exit 2` 로 실경로를 다시 구하고 비었음·`/`·리포지토리 안이면 `undo_created_dirs`(이번 실행이 만든 꼬리만 깊은 쪽부터 `rmdir`, 비어 있지 않거나 기존 디렉터리는 못 지운다) 후 exit 2.
- (B) 사본에 `docs/` 를 `tar` 로 복사하고 `chmod -R a-w`(`$WORK/docs`, 테스트의 `res://../docs` 와 같은 상대 위치). `safe_remove_work` 는 삭제 직전 `chmod -R u+w` 로 풀고 지운다(비 root 에서도 삭제되는지 확인함, 아래 "보강").
- 요약 awk: Run Summary 항목(`- <테스트명>`) 아래에 `[Failed]` 줄이 있으면 "실패한 테스트", 없으면(Pending/Risky 뿐) "Pending/Risky 테스트(N건, 실패 아님)" 로 따로 표시.
- 머리 주석·`tools/bot/README.md`(환경 변수 절 4단계, exit 2 설명, 주의 절, 자체 테스트 기준 4번 추가)를 실제 동작과 맞춤. "만들기 전에 exit 2" 문구는 "만들기 전 + 만든 뒤 방어선" 으로 정정.
