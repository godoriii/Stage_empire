## 셰이더 컴파일 확인 (문서화)

헤드리스 GUT 는 더미 RenderingServer 라 `.gdshader` 를 컴파일하지 않는다. `recapture.sh` 의 Xvfb 캡처는 `grid_sandbox.tscn` 이 toon(시안 A/B/C) + outline(next_pass) 머티리얼을 실제로 그리므로 **캡처 자체가 gl_compatibility 셰이더 컴파일 확인을 겸한다.** 컴파일이 실패하면 (a) 로그에 `SHADER ERROR`/`Shader compilation failed` 가 남고 (b) 렌더가 달라져 기준 PNG 와 픽셀 차가 생긴다. 스크립트는 (a)를 즉시 실패로 처리하고 (b)는 `compare_png.gd` 가 보고한다. 별도 셰이더 전용 단계는 두지 않는다. 한계: forward_plus(Vulkan) 컴파일은 검증하지 않는다(티켓 제외 항목).

### AC2 오류 주입(스크래치 프로젝트 사본)

실제 `project/view` 는 건드리지 않고 `project` 를 스크래치로 복사한 뒤 사본의 `view/shaders/toon.gdshader` 끝에 `uniform float broken_syntax = ;` 를 덧붙였다. `SE_PROJECT_DIR` 은 `recapture.sh` 가 캡처할 프로젝트 경로(기본 `project`)로, 이 검증 전용이다.

```
$ SE_PROJECT_DIR=<scratch>/proj_bad/project project/tests/view/screenshots/recapture.sh <scratch>/shots_bad2 ; echo rc=$?
== capture grid_yaw45_zoom2.png
FAIL: grid_yaw45_zoom2.png 로그에 셰이더 오류 패턴 'SHADER ERROR' (로그: <scratch>/shots_bad2/grid_yaw45_zoom2.log)
23:SHADER ERROR: Expected constant expression after '='.
rc=1
```

(로그 발췌: `--res://view/shaders/toon.gdshader-- … E 60-> uniform float broken_syntax = ;`, `ERROR: Shader compilation failed.`) 중복 정의(`void fragment` 2회)로도 시도: `SHADER ERROR: Redefinition of 'fragment'.` → rc=1. 캡처 자체는 종료 코드 0 이었으므로(Godot 는 셰이더 오류에도 종료하지 않는다) **로그 패턴 검사가 필수**다.
