## 3. 구현 메모

- 개최는 `ShowSim` 이 구간 단위로 진행하고 돌발 카드에서 멈춘다(`advance()` → `{kind:"event"}` → `choose(id)`). 봇은 `runAll(chooser)`, 브라우저는 박자마다 화면을 그린다.
- 미리보기·봇 평가는 같은 시뮬을 분산 0·돌발 없음으로 돌린다(`preview`, `evaluate`).
- 2막 이후 손잡이(홍보·음향 등급·푸드·청소·의료·바 부스)는 스펙 공식대로 넣었고 수치 검증은 안 했다. **날씨는 데이터 테이블이 없어 미구현**(show.md Q4).
- 엔진에 카드 id 별 분기 없음(RW6): 효과 타입(pct/add/rule/money/fame/shield)과 키로만 처리.
