## 구현 요약

`tools/bot/mutate_and_test.sh`

- `BASE="${SE_MUTATE_DIR:-${TMPDIR:-/tmp}}"` 를 **디렉터리를 만들기 전에** 판정한다: `resolve_no_create` 가 존재하는 가장 가까운 상위를 `pwd -P` 로 풀고 없는 나머지 경로를 붙여 실경로를 구한 뒤, `"$ROOT"|"$ROOT"/*` 이면 exit 2. (`mkdir -p` 를 먼저 하면 AC2 의 "`project/tests/_mut_tmp` 없음" 을 못 지킨다.) 아직 없는 경로 중간에 `..` 가 있으면 위치를 판정할 수 없어 exit 2.
- 통과하면 `mkdir -p` → `BASE="$(cd "$BASE" && pwd -P)"` → `mktemp -d -p "$BASE" se_mutate.XXXXXX`.
- `safe_remove_work`: 비어 있지 않음 + 디렉터리 + 실경로가 `"$BASE"/se_mutate.?*` 일 때만 `rm -rf`. 리포지토리 밖 조건은 `$BASE` 검사에, 이름 조건은 패턴에 들어 있다.

`tools/bot/README.md`: 환경 변수 절 "리포지토리 밖" 문장, exit 2 설명(알 수 없는 옵션/인자 초과/`..`·절대 경로/리포지토리 안 상위 디렉터리), 빈 패치 규칙(0 바이트만), `git diff --no-index` 예시, 주의 절·자체 테스트 3번 갱신.

### 택일 결정 (AC4): README 명시

`grep -q '^@@'` 로 빈 패치 취급하는 안은 채택하지 않았다. 잘못된 파일(README, 잘린 diff 등)이 조용히 "기준선 exit 0 = 변이를 못 잡았다" 로 둔갑하기 때문이다. 지금은 `patch` 가 exit 3 과 `Only garbage was found` 를 내므로 실수가 바로 보인다.

### 티켓 문구와 다른 점 1건 (`--no-index` 예시)

티켓은 `git diff --no-index` 예시에 `--src-prefix=a/ --dst-prefix=b/` 를 넣으라고 했으나 **실측으로 틀린 처방**임을 확인했다. 이 두 값은 git 기본값이라 효과가 없고, 두 경로 인자가 그대로 접두어 뒤에 붙는다.

```
$ cd <작업폴더>      # a/project/sim/economy.gd (원본), b/project/sim/economy.gd (변이본)
$ git diff --no-index --src-prefix=a/ --dst-prefix=b/ a/project/sim/economy.gd b/project/sim/economy.gd | head -1
diff --git a/a/project/sim/economy.gd b/b/project/sim/economy.gd      <- patch -p1 로 적용 불가
$ git diff --no-index --no-prefix a/project/sim/economy.gd b/project/sim/economy.gd | head -1   (b/ 로 바꿔 입력)
diff --git a/project/sim/economy.gd b/project/sim/economy.gd           <- 올바름
$ git diff --no-index --src-prefix= --dst-prefix= …                     <- --no-prefix 와 같은 결과
```

`--no-prefix` 로 만든 패치를 사본에 `patch -p1 --dry-run` 해서 `checking file project/sim/economy.gd` 로 적용 가능함을 확인했다. README 에는 이 올바른 형태(디렉터리 이름을 `a/`·`b/` 로 두고 `--no-prefix`)를 쓰고, `--src-prefix=a/ --dst-prefix=b/` 가 왜 안 되는지 한 줄 적었다.

## 리뷰어에게

1. AC2·AC3 소스 대조 지점: `tools/bot/mutate_and_test.sh` 의 `resolve_no_create`·`BASE_PRE` 판정(사본·디렉터리 생성 전), `safe_remove_work`(`case "$w" in "$BASE"/se_mutate.?*)` 하나). 심링크: `BASE` 와 `w` 모두 `pwd -P` 실경로라 macOS `/tmp -> /private/tmp` 에서도 일치한다(이 환경에는 macOS 가 없어 `TMPDIR` 가 다른 실경로인 케이스로만 확인).
