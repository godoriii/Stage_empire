AC13 사람 캡처가 사실상 이 검증을 겸한다.
- 비용(fps)·GPU 시간: 사람 PC 필요.

### 그 밖의 확인 요청

- 티켓·구현자 보고에서 AC8/AC12 등의 스펙은 충족하지만, `ShaderVariants.apply()` 가 없는 id 에서 `-1` 을 반환하고 `push_error` 하는 동작은 티켓에 정의가 없다(테스트 `test_apply_rejects_unknown_id_without_changes` 로 고정됨). `SpikeCrowd._ready` 는 없는 시안에서 에러를 내고 default 로 폴백하며(구성 오류 처리와 같은 방식), 측정기는 그 전에 종료 코드 2 로 막는다. 의도적으로 보여 문제 아님.
- 셰이더 컴파일이 헤드리스 GUT 에서는 검증되지 않는다(더미 RenderingServer 라 `get_shader_uniform_list()` 가 빔 — 테스트가 소스 텍스트 파싱으로 대체). 컴파일 검증은 Xvfb 캡처(gl_compatibility)뿐이므로 CI 에 Xvfb 캡처 비교 단계가 없으면 셰이더 파손이 CI 에서 안 잡힌다. 후속 CI 티켓 후보(이번 티켓 범위 아님).
- 스크린샷 PNG 는 LFS 대상이다(`.gitattributes`). 이 worktree 에는 실제 PNG 가 있어 비교·테스트가 가능했다. CI 체크아웃에서 `git lfs pull` 이 없으면 `test_se004_screenshots_exist_1080p` 와 qa 추가 `test_se004_outline_qa.gd` 가 PNG 로드에서 실패한다(SE-002 때 열린 이슈와 같음).
- qa 추가 파일: `project/tests/view/test_se004_outline_qa.gd`(+ Godot 이 생성한 `.uid`). 커밋 대상이다.
